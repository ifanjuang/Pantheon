# Architecture Review Card Candidate Template

Status: template candidate — non-executable.

A Review Card Candidate is a compact decision surface derived from a Task Contract Candidate, Context Pack Candidate, Evidence Pack Candidate and Result Candidate.

It is not proof.
It is not approval.
It is not a deliverable.
It does not authorize external action.
