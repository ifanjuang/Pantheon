# 04 — Administration / Third Parties

Status: communication pattern folder — candidate-only.

Use this folder for patterns addressed to administration, concessionnaires, syndics, AMO, finance actors or other third parties.

Typical acts:

```text
request information;
transmit project source material;
clarify procedural status;
ask for confirmation;
separate funding / administration constraints from design responsibility;
record missing pieces.
```

Typical gates:

```text
source_pack_required for official submissions or procedural positions;
human_review_required before external transmission;
raw administrative output must not become project truth without review.
```
