# 07 — Internal Review

Status: communication pattern folder — candidate-only.

Use this folder for internal notes, risk summaries, evidence tree outputs and review checklists.

Typical acts:

```text
summarize risk;
prepare evidence tree;
classify source gaps;
prepare reviewer notes;
mark decision needed;
record rejected wording;
prepare Notion / issue follow-up.
```

Typical gates:

```text
not for external transmission;
source status must be visible;
reviewer and decision status must be explicit.
```
