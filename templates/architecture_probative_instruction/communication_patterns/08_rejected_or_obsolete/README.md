# 08 — Rejected / Obsolete Patterns

Status: communication pattern folder — candidate-only.

Use this folder to keep trace of wording patterns that should not be reused.

Typical reasons:

```text
unsafe admission language;
unclear role boundary;
too accusatory;
too vague;
source basis missing;
mission perimeter unclear;
superseded by a safer pattern;
rejected by human review.
```

A rejected pattern should explain why it was rejected and what replaces it, if anything.

```text
Rejected does not mean deleted.
Keeping rejected patterns prevents unsafe reuse.
```
