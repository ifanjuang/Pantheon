# 02 — Contractors / Entreprises

Status: communication pattern folder — candidate-only.

Use this folder for patterns addressed to contractors or suppliers.

Typical acts:

```text
request status;
request source / justification;
clarify contractor scope;
record open items;
request schedule;
separate quote from validated order;
recall execution responsibility;
prepare reserve follow-up.
```

Typical gates:

```text
source_pack_required for extra works, delay, reserve, payment or replacement contractor topics;
human_review_required before any external transmission;
no wording should decide responsibility by itself.
```
