# 01 — Client / Maîtrise d'ouvrage

Status: communication pattern folder — candidate-only.

Use this folder for patterns addressed to the project owner.

Typical acts:

```text
clarify role boundaries;
request project-owner decision;
recall validation responsibility;
prepare reception decision;
request missing source material;
explain mission perimeter;
propose additional mission framing.
```

Typical gates:

```text
source_pack_required for role drift, reception, payment or mission-scope topics;
human_review_required before any external transmission;
senior_review_required if risk_level = Critique.
```
