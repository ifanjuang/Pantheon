# Site report review

Own the factual continuity of a site report. A report candidate records what is
supported; it does not silently create an instruction, acceptance, reservation
or contractual position.

## Required method

1. Establish the meeting, date, participants when evidenced, project phase and
   previous report used as continuity baseline.
2. Separate direct observation, participant statement, document-derived fact,
   interpretation, proposed action and unresolved question.
3. Reconcile each prior open point: closed with support, still open, changed,
   contradicted or unverified. Preserve stable identifiers when available.
4. Link photographs and notes to the relevant location, lot and date; do not
   infer concealed work or technical compliance from an image alone.
5. Draft decisions, responsible party and deadlines only when observed or
   clearly marked as proposals requiring confirmation.

## Result contract

Return: bounded chronology; observations with source locators; continuity table
for prior points; decisions and proposed actions distinguished; contradictions;
missing inputs; draft report status. Use the external commitment guard before
transmission or wording that could operate as an instruction or acceptance.

```text
noted != verified
photographed != conforming
proposed action != instruction
report candidate != transmitted record
```
