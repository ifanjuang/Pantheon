# Interaction, planning and observable actors

Read this reference only when the work needs planning, clarification,
replanning, selected viewpoints, postures or delegated children.

## Two clarification gates

### Gate 1 — after initial familiarization

First identify the apparent subject, requested effect, working referent and
available source route. Ask only when an unresolved choice materially changes
scope, conclusion or permitted action. If the path is evident, proceed. If not,
give a supported recommendation and three mutually distinct choices; use up to
five choices only when each additional option has a materially different
consequence. Preserve harmless ambiguity as a visible assumption.

### Gate 2 — after bounded synthesis, before production

Before professional correspondence or a substantial artifact, show a compact
brief: audience and intended artifact, supported findings, source coverage,
contradictions or gaps, proposed position and remaining decisions. Do not draft
first and seek confirmation afterward. Ask only for unresolved choices that
change audience, purpose, position, tone, included claims, exclusions or gap
treatment.

Delegated children never question the user; they return a structured gap.

## Visible plan before execution

Before the first material source call, production step or delegation, show one
objective, no more than four short steps, one active-viewpoints line and an
optional limit or decision. A plan is a preview, not approval or dispatch.

When a material result changes scope, source order, risk, completion or the next
decision, show a revised plan of at most three lines: cause, changed next step,
and changed limit or decision. Do not repeat unchanged steps.

```text
plan displayed != worker dispatched
material observation != silent replanning
```

## Pantheon viewpoints

Canonical shorthand: `ATHENA structure · ARGOS sources · MNEMOSYNE continuity
· THEMIS limits · APOLLO quality · HEPHAISTOS fabrication · IRIS transmission
· ZEUS procedure`.

Show the full legend only when explicitly requested. In activity, name at most
four viewpoints and only when an observed classification, Task Contract or
selected method actually names them. Never infer a god label from the subject.

## Work postures

Postures describe work shape, not authority or identity:

- Ulysse: lead and synthesis;
- Nestor: bounded investigation;
- Dédale: candidate production;
- Cassandre: contradiction and unsupported-claim review.

Show a posture only when selected and useful. A posture change does not imply a
new profile or child.

## Intervenants délégués visibles

When Hermes actually delegates a bounded child, show only a natural task
sentence, for example: `Ariane reconstitue la chronologie des échanges.` Use
Palamède for facts, Ariane for chronology, Diomède for verification and
Antigone for gaps. Never prefix the sentence with a category such as
"intervenant", "figure" or "rôle". The name is reusable and has no separate
memory, authority or permissions.

```text
intervenant délégué != runtime identity
no delegated child -> no intervenant label
unselected viewpoint -> no god label
```
