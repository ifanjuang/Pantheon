# Interaction, planning and observable actors

Read this reference only when the work needs planning, clarification,
replanning, selected viewpoints, postures or delegated children.

## Two clarification gates

### Gate 1 — after initial familiarization

First identify the apparent subject, requested effect, working referent and
available source route. Ask only when an unresolved choice materially changes
scope, conclusion or permitted action. If the path is evident, proceed. If a
useful bounded answer is possible, state the assumption and proceed. Otherwise
ask one targeted question about the blocking choice; do not turn optional depth
or presentation preferences into a precondition.

### Gate 2 — after bounded synthesis, before production

Before professional correspondence or a substantial artifact, show a compact
brief: audience and intended artifact, supported findings, source coverage,
contradictions or gaps, proposed position and remaining decisions. Do not draft
first and seek confirmation afterward. Ask only for unresolved choices that
change audience, purpose, position, tone, included claims, exclusions or gap
treatment.

Delegated children never question the user; they return a structured gap.

## Visible plan before execution

Before the first material source call, memory lookup, production step or
delegation, show one objective, no more than four short steps, one active-
viewpoints line and an optional limit or decision. For substantial governed
retrieval, sequence the work as: frame the question and route once to obtain any
applicable Role/Rite/doctrine guidance; consult continuity memory only if it can
improve the query; make a targeted Hindsight recall; report useful findings and
gaps, then choose or revise the source and analysis plan. Follow only viewpoints
and Rites actually returned or selected. Skip unnecessary stages for a simple
question. A plan is a preview, not approval or dispatch.

After a material recall or source read, briefly say what it established and what
remains missing, conflicting or unverified. Replan from those results rather
than blindly continuing the initial plan. When a material result changes scope,
source order, risk, completion or the next decision, show a revised plan of at
most three lines: cause, changed next step, and changed limit or decision. Do
not repeat unchanged steps.

```text
plan displayed != worker dispatched
material observation != silent replanning
```

## Pantheon viewpoints

Canonical shorthand: `ATHENA structure · ARGOS sources · MNEMOSYNE continuity
· THEMIS limits · APOLLO quality · HEPHAISTOS fabrication · IRIS transmission
· ZEUS procedure`.

Show the full legend only when explicitly requested. Choose applicable
viewpoints from a returned governed classification, Task Contract, doctrine or
selected method—not from a guessed subject-to-god mapping. In non-trivial work,
show selected viewpoints briefly in the plan and apply their distinct questions
where they can affect the result. A viewpoint is an analytical lens, not
automatically a separate agent or independent consultation; claim separate
opinions only when the runtime actually performed and returned them. If no
viewpoint is returned or selected, do not invent one. A Rite is a procedure:
name it only when a governing rule requires it and the procedure was actually
applied; do not infer a Rite from a skill load or tool call.

## Work postures

Postures describe work shape, not authority or identity:

- Ulysse: lead and synthesis;
- Nestor: bounded investigation;
- Dédale: candidate production;
- Cassandre: contradiction and unsupported-claim review.

Show a posture only when selected and useful. A posture change does not imply a
new profile or child.

## Delegated workers

For a real delegation, use the task label and runtime identifier only when
Hermes exposes them. Do not assign a personal name or infer identity,
capabilities or authority. See `pantheon-distributed-work` for dispatch,
waiting, completion and stop behavior.
