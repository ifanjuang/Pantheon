# Vocabulaire métier du bâtiment

Repères pour comprendre une question et choisir la source. Ce n'est pas une source
de valeurs : une exigence, une dimension ou un seuil se lit dans la pièce du projet
ou dans la Bibliothèque. Un terme absent d'ici ou ambigu : le chercher dans la
Bibliothèque (`recall_knowledge_memory`, glossaire et guides) avant de répondre ;
sinon demander ce que l'utilisateur entend.

## Maquettes : discipline et catégorie

- Une maquette d'**architecture** contient les locaux, ouvertures, murs, cloisons et
  parfois des poteaux et poutres d'**ossature** (bois) : ce ne sont pas ceux du BET.
- Une maquette de **structure** (BET, « structure », « béton armé », « charpente du
  BET ») contient poteaux, poutres, semelles, dalles, sans locaux : ses éléments
  prennent les locaux de l'architecture par recalage (confiance estimé).
- Les maquettes **fluides** (CVC, plomberie, électricité) sont rares ; à défaut, les
  plans et CCTP du lot répondent.
- Quand une question nomme un lot ou une discipline, demander les éléments de cette
  discipline (« … du BET », « … archi ») ; quand plusieurs maquettes répondent,
  regarder la discipline de chacune avant de choisir.

## Pièces : numéro, indice, date

- Le **numéro de pièce** désigne le document dans le dossier (PC2, PCMI2, A-101,
  CCTP lot 03) ; il ne change pas d'une version à l'autre.
- L'**indice** désigne la version (A, B, C ; 01, 02 ; parfois préfixé par la phase,
  S2, PRO-B) ; il se lit dans le cartouche ou le tableau des indices, jamais dans
  le nom du fichier seul.
- La **date** de l'indice se lit au même endroit ; la date du fichier n'est qu'un
  repère, à dire comme tel.

## Normes et réglementation

DTU (règles de l'art par ouvrage), Eurocodes (calcul des structures), RE2020 (énergie
et carbone du neuf), réglementation incendie, accessibilité (PMR), acoustique, NF
produit, avis techniques. Toujours citer le texte lu dans la Bibliothèque (édition,
article) ; ne jamais donner un seuil de mémoire.
