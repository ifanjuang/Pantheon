Between your question and the answer, what is AI actually doing?

On screen, everything feels immediate. Behind the answer, the system receives context, retrieves useful passages, sometimes remembers, sometimes acts — and we still need to know what the result is actually worth. This page follows that path without unnecessary jargon.

Pantheon is not another AI.

It keeps the work readable when sources, versions, responsibilities and decisions start to matter.

The map before the details

The essentials fit into six ideas.

Technical terms become simpler once each one has a clear job.

01 · Produce

The model

The engine that composes the answer.

It writes, compares, analyses or reasons from what it is given. It does not automatically have your entire dossier in view.

02 · Make available

Context

What is on the desk right now.

The question, instructions, excerpts, tool results or useful memories: this is the material available for the task.

03 · Retrieve

RAG

Search before answering.

It looks through the sources for useful passages and brings them to the model when they are needed.

04 · Continue

Memory

What prevents every task from starting at zero.

It carries continuity through time. But a memory still belongs to a dossier, a date, a version and a status.

05 · Do

The executor

The part that carries out the mission.

It mobilizes models, tools and reusable know-how, works through several steps and returns a result.

06 · Keep the frame

Pantheon

What keeps the path reviewable.

Mission, scope, sources, capabilities, provenance, evidence, statuses and decisions do not dissolve into one polished answer.

1 · Retrieve

AI answers with what it actually has in front of it.

A model may be excellent and still miss the decisive piece. Context must therefore be prepared, and the right material retrieved without pouring an entire library into every request.

Context

The working desk.

Too empty and a key piece is missing. Too full and it becomes noisy. Good context contains what the mission actually needs.

Tokens

The units a model handles.

Text is broken into small units, and the amount a model can inspect at once remains finite. That is one reason useful passages are selected.

The chunk

A piece that keeps its address.

A long document is prepared as searchable passages. Each piece stays linked to its document, page, section and, when possible, the version it came from.

The embedding

A mathematical representation of semantic proximity.

It helps bring together different wordings that are nevertheless about the same subject.

Why combine exact search and semantic search?

An index, reference or exact name is often easy to find by words. The same idea expressed differently may be easier to retrieve by semantic proximity. Hybrid retrieval combines both and then ranks the results.

That ranking helps retrieval. It does not give the top passage any special authority.

What might be retrieved in LIA21?

The ventilation question may bring back a specification, a meeting note and an inspection record. The model can use them to draft a reply; we still need to know which piece is newer, which revision applies and what each one actually supports.

2 · Organize

Memory is only useful if we know what it belongs to, where it came from and when it applied.

One giant memory eventually mixes projects, experiments and old assumptions. Continuity becomes useful when it stays classified, dated and reversible.

Three working-memory domains

A

Agency

What deserves to be reused.

Methods, references, templates, working habits and lessons that outlive one particular dossier.

P

Projects

What belongs to one case.

Meetings, hypotheses, decisions, drafts, exchanges and context that belong to LIA21, SOL14 or another dossier.

S

Sandbox

What can be tested without blurring real dossiers.

Synthetic data, new models, new versions and experimental integrations stay isolated from professional dossiers.

These domains organize working memory. They do not replace task scope, information status or navigation categories.

This lets the system search LIA21 without silently letting SOL14 leak into the answer. Categories and tags may help navigation; they are not evidence or authorization.

Versions: keep the history without mistaking old for current

Keep the trace

An older revision may explain why a decision was made. Deleting it would erase part of the history.

Recover the applicable state

Index, date, active revision, supersession and obsolescence need to remain visible so an old passage does not quietly return as current.

Why Markdown?

A Markdown file, usually ending in .md, is plain text with a few simple marks for headings, lists and links.

# LIA21 — 14 August meeting

## Ventilation
The inspection still needs confirmation.

- expected source
- contractor reply pending

It stays readable without specialist software, easy to compare across versions, easy to search and practical for both people and AI tools. Most importantly, it is portable: the content does not depend on one application to remain understandable.

The format does not change the authority of the source. A received PDF remains the received PDF. Markdown produced from it is a working representation that should continue to point back to the original.

Good memory does not merely ask “what looks similar?” It searches in the right place, by the right method, then checks whether what it found still applies.

This is Mnemosyne’s territory, as Pantheon’s canonical continuity role. She directs retrieval toward the right domain or dossier, chooses the appropriate search strategy, watches for duplicates, indices, dates, versions and superseded records. The executor performs the retrieval; Mnemosyne keeps the memory discipline.

Memory · MNEMOSYNE

Where should we look?

Active Project, Agency, Sandbox, working corpus, qualified sources or the Register: scope comes before the search engine.

Retrieval · MNEMOSYNE

How should we look?

Exact words, semantic proximity, chronology and declared relations can be combined. The question chooses the method.

Continuity · MNEMOSYNE

What should be kept, and where?

She may propose session, Project, Agency, Sandbox, archive or Register Candidate. A proposed destination never becomes promotion by itself.

What about conversational memory?

It can make an assistant more convenient by retaining preferences or continuity. For a governed task, its injection may be limited or disabled so the result rests on explicit context rather than invisible recall.

3 · Act

An answer changes nature once it can produce an effect.

Opening a file, searching the Web, calling an API, editing a document or preparing a send means distinguishing what knows, what knows how, and what actually executes.

The tool

A concrete capability.

Read, search, calculate, export, call a service or write somewhere.

The skill

A reusable way to do the job well.

The tool opens the PDF; the skill describes how to analyse it, what to check and how to return the result.

The agent

An objective rather than one immediate answer.

It can observe, choose a step, use a tool, read the result and continue toward the expected output.

The executor

The engine that actually does the work.

An external agentic engine or service receives a bounded mission. Pantheon must be able to replace it without changing its own responsibility.

The run

This particular execution.

The same task run tomorrow creates another run, with its own events, tool calls and results.

The workflow

The repeatable method.

It describes a path through the work. The executor that follows the path remains a separate responsibility.

API, connector, MCP: three words for three levels

An API lets two pieces of software communicate in a structured way. A connector adapts a particular service. MCP provides a shared convention for exposing tools and resources to AI systems.

These mechanisms make connection easier; they do not decide whether a capability is authorized for this mission.

Task, session, run: the simplest distinction

The task says what must be accomplished. The session carries the thread of an interaction. The run is one concrete execution. A session can therefore contain several tasks and several runs.

4 · What can count

Producing an answer is easy. Knowing what it allows is another matter.

In LIA21, one sentence says the ventilation is compliant. The model can turn that into an excellent email. The dossier still asks: which document, which date, which index, what scope, what inspection?

?
Which document? Which version? Who is speaking? Is there a newer piece? Is this a statement, an observation, an approval?

Pantheon keeps the path reviewable: not to declare truth for the professional, but to stop a conclusion from losing the conditions it came from.

The mission brief

What is requested, allowed and expected.

The Task Contract states intent, scope, constraints, useful Pantheon viewpoints, approvals, expected evidence, allowed or forbidden outputs and memory rules.

The execution green light

This exact mission may proceed.

Execution Admission checks launch conditions. It does not say the run already happened or that its future result will be valid.

Provenance

Being able to return to the origin.

Document, email, Web, memory, calculation, tool or person: the conclusion keeps a path back to the actual material.

Candidate result

A result whose status has not yet changed.

Execution may be technically complete while the content remains a draft to review, discuss or approve.

Evidence Item

One item supporting one bounded point.

An Evidence Item links a claim to a source, a locator and an explicit support scope.

Evidence Pack

The review dossier for the result.

It gathers sources, evidence, assumptions, actions, risks, outputs, reviews and approval state.

Register Candidate

What we may want to retain durably.

Before the Probative Register, an item can remain a candidate with scope, provenance, certainty, risk and remaining validations.

The Probative Register

What remains together with the reasons it may be relied on.

It retains qualified, sourced and reviewable assertions. It is not a pile of whatever the assistant remembers.

The question for the human

Make the missing decision visible.

When arbitration becomes necessary, Pantheon presents the question, options, missing material and blocked action. A request for decision is still distinct from the decision.

Why does Pantheon avoid one “reliability” score?

Because four different questions would be crushed into one number: what evidence do we have? what has actually been verified? what are the consequences? who still needs to approve?

E · Certainty

How strong is the probative support for the claim?

V · Verification

What has actually been checked or observed?

K · Consequence

What could happen if we act or conclude on this basis?

C · Approval

What level of decision is still required?

The technical codes E0–E4, V0–V4, K0–K4 and C0–C5 make these axes comparable without collapsing them together.

The eight canonical Roles: eight angles of judgment

They are not all invoked at once. A mission calls only the viewpoints that can materially improve the decision or prevent a bad status change.

Structure · ATHENA

Athena puts the problem in order.

She clarifies the goal, decomposes what needs decomposing and notices when a request expands without limit.

Useful when objectives, phases or decisions are tangled together.

Sources · ARGOS

Argos asks what the claim rests on.

He examines provenance, source quality, missing pieces and contradictions that weaken a claim.

His viewpoint matters whenever we need to show where a statement came from.

Continuity · MNEMOSYNE

Mnemosyne finds the right state in time.

She knows where to search history, how to search it, which version or index matters now, and where retained material should be proposed to live.

She becomes useful whenever a memory, prior decision, duplicate or version can change the answer.

Limits · THEMIS

Themis looks at how far we may go.

Mission, risk, rule, responsibility and approval level: she makes limits visible before they are crossed.

Especially valuable before external action or a consequential conclusion.

Quality · APOLLO

Apollo rereads what already looks finished.

He looks for gaps behind polished wording: clarity, completeness, sufficient evidence and readiness to present.

The last-review viewpoint before a draft begins to look too much like a deliverable.

Fabrication · HEPHAISTOS

Hephaistos prepares what needs to be built.

He qualifies the structure of a document, export, patch or other candidate artifact. The executor then performs the admitted production.

Useful when an intention must become something concrete without confusing fabrication with validation.

Transmission · IRIS

Iris looks at what is about to cross the door.

Recipient, channel, wording, ambiguity and message effect: she shapes transmission without rewriting the underlying decision.

Important before a send, especially when tone, confidentiality or responsibility matter.

Arbitration · ZEUS

Zeus qualifies the next procedure.

Faced with conflict or variants, he may keep a draft, request a piece, narrow scope, block a passage or return the choice to the human.

He appears when the next move itself needs deciding. He does not decree truth.

The Task Contract connects these viewpoints to a real mission. It can name an owner Role and a few useful viewpoints rather than activating the whole college by reflex.

Mnemosyne and Argos: where is the boundary?

Argos asks about the value of a source: where did it come from, what does it support, what is missing?

Mnemosyne asks which state of history is in play: where should we look, which version or index is current, what was superseded, what is duplicated, and where should the next retained item belong?

Both may inspect a date or version, but for different reasons. The newest memory is not automatically the strongest source.

And where does Hermes fit?

Hermes Agent is an execution-side candidate: an external engine may receive a bounded mission, use the required capabilities and return the run result. A Pantheon viewpoint remains a governance jurisdiction; a posture, Method or Skill guides the work. A distinct Hermes Profile is justified only by a real runtime boundary — for example different credentials, context or memory injection, tool surface, data exposure, or execution isolation.

Mnemosyne therefore does not require a dedicated Hermes Profile: the Role frames memory retrieval; the executor performs the admitted retrieval inside the appropriate runtime boundary.

Rites: when a precise method is better than one more answer

A Rite is a temporary review procedure. It treats a recognizable difficulty; it is neither automatic nor necessary for every task.

Controlled Divergence

We converged too quickly on one path.

Open several possibilities before criticizing them and converging.

Contradictory Self-Review

The first result is too convincing to accept without resistance.

Reread it as a third party would, looking for weaknesses, omissions and contradictions.

Source Concordance

Several pieces discuss the same point without saying exactly the same thing.

Compare date, scope, actual support and contradictions before relying on them.

Hidden Premises

A reasoning chain stands on assumptions nobody has stated.

Make them visible before they become invisible constraints.

Session Refoundation

The thread has become too long or too burdened by old assumptions.

Restart from clean bounded context instead of stacking more onto it.

And sometimes: no Rite.

A simple task deserves to stay simple.

Governance matters only when it genuinely improves decision quality, evidence or risk control.

Spaces: do not let something count in the wrong place

Spaces are governance distinctions, not necessarily folders or screens. They separate what should endure as a rule, what belongs only to one Project and what remains open to deliberation.

They are different from Agency / Projects / Sandbox. Those organize working memory; the Spaces below describe the context in which an activity or decision has meaning.

Reusable

Governance Reference Space

Rules, methods, statuses and principles intended to outlive one dossier.

It stops a habit from LIA21 from silently becoming a general rule.

Bounded

Project Space

Sources, constraints, decisions, candidate evidence and context belonging to one defined case.

It keeps LIA21 separate from SOL14 when several dossiers coexist.

Deliberation

Agora

The conceptual place where positions and what sources can no longer settle are made visible.

Useful for professional preference, legitimate alternatives or disagreement requiring a human decision.

Does all of this already exist as machine schemas?

Not uniformly, and deliberately so. Task Contracts, Role Signals, Evidence Packs, Register Candidates and several other objects already have validation contracts. Rites and Spaces remain primarily documented governance grammar.

Candidate technologies

Functions outlast products.

The names below are candidates being studied today. They do not define the architecture and may be replaced.

Agentic execution

Hermes Agent is being studied as the main external-executor candidate: receive a bounded mission, mobilize models, skills and tools, then return the run result.

candidate · replaceable

Documents and workspace

The selected productive target keeps NAS / AFFAIRES as the only durable store for professional source files. Linux mounts that tree directly; Workspace indexes it without creating a durable local source mirror. Hidden Markdown cartouches may sit beside sources to describe them without replacing them. Obsidian, LiveSync, and CouchDB remain historical qualifications or optional tools, not dependencies of this topology.

selected target · bounded candidate implementation

Derived memory and retrieval

Hindsight now receives, on the AFFAIRES target, bounded operations produced by Workspace from admitted sources. Its chunks and memories remain retrieval derivatives: they help recall and relate, but replace neither the NAS file, its provenance, nor Evidence. An on-demand Hermes reconciliation may propose a critique without automatically mutating that memory.

selected candidate · bounded producer · live qualification open

Memory alternative

TencentDB Agent Memory has been evaluated. The tested topology raised state-consistency and identity-isolation problems; activation is deferred and may be revisited.

evaluated · deferred

Document analysis

Docling is the preferred candidate for extracting useful structure: headings, paragraphs, tables, reading order and derivatives linked back to the source. Execution-layer integration remains a separate qualification topic.

preferred candidate · integration to qualify

Do not confuse the names: Pantheon Role MNEMOSYNE is a governance responsibility. Any external product also called “Mnemosyne” remains a distinct replaceable technology candidate.

Data and confidentiality

Cloud is not an architectural requirement.

The chain can remain local when the selected components allow it.

On the current AFFAIRES target, professional files remain on the NAS and are read in place from the Linux mount. Workspace’s SQLite index is reconstructible; Hindsight retains retrieval derivatives within its own storage boundary without becoming the source owner. Extraction, retrieval, databases, and models can also run locally when the selected components support it.

Cloud remains available when an external capability is useful and accepted. Web search, a hosted model or a third-party API then crosses the local boundary explicitly.

The real question is not “all local” versus “all cloud”. It is knowing, for each capability, where the data goes, what persists there, and why.

Local

The stack stays in the private environment when the selected models and services allow it.

Hybrid

Sensitive data stays local while a few external capabilities are called explicitly and within bounds.

Cloud

Hosted services can be chosen when they provide the right capability. Availability does not make them mandatory.
