De l’indice visuel à la décision tracée.

La photo ne devient pas automatiquement un constat. Le workflow rattache l’image au chantier, relit les pièces, estime le risque, vérifie le mandat actif, pose une question et prépare une suite candidate : compte rendu, relance, alerte planning ou courrier formel.

Exemple : photo Telegram → contexte chantier → analyse image → CCTP/CR/DTU → gate mandat → point CR ou escalade.
