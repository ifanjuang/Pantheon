# Hercule — matrice de reconciliation

Status: support documentaire, non canonique, non executable.

Portee : document-pont de reconciliation pour les douze epreuves Hercule du corpus Ulysse / Hercule.

Ce fichier ne remplace pas `hercule_ai_discipline.md`.

Il stabilise les plaques, sous-titres, maximes, distinctions et renvois vers les fiches longues.

Il ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Regle de lecture

Hercule ne reduit pas l'IA au silence.

Il transforme une puissance generative en discipline situee.

Chaque epreuve isole une force differente de l'IA : puissance, proliferation, intention, chaos, matiere, attention, action, autonomie, transmission, attelage, livrable et memoire.

La progression finale doit eviter deux erreurs :

```text
tout reduire au controle ;
tout transformer en runtime agentique.
```

Pantheon conserve la doctrine :

```text
preuve avant validation ;
statut avant transmission ;
mandat avant action ;
humain avant canonisation.
```

## Distinctions critiques

### Taureau / Juments / Ceinture / Boeufs

```text
Taureau  : l'action doit recevoir des conditions.
Juments  : l'autonomie doit recevoir un terme.
Ceinture : la transmission doit recevoir une legitimite.
Boeufs   : les forces doivent recevoir un attelage situe.
```

### Boeufs / Pommes / Cerbere

```text
Boeufs  : comment le travail est agence.
Pommes  : ce qui peut devenir livrable assumable.
Cerbere : ce qui peut rester et revenir.
```

### Source / preuve / sortie / memoire

```text
Une source n'est pas une preuve.
Une sortie n'est pas un livrable.
Un candidat n'est pas un valide.
Un usage ponctuel n'est pas un droit de demeure.
```
