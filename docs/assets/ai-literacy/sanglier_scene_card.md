# Sanglier d'Erymanthe — dompter le contexte

Status: support documentaire, non canonique, non executable.

Portee : fiche detaillee pour les diptyques pedagogiques Ulysse / Hercule.

Cette fiche complete `hercule_ai_discipline.md` et devra etre integree a une future version longue reconciliee du corpus Hercule.

Elle ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Repartition avec la Biche

Cette fiche distingue deux epreuves proches mais differentes :

```text
Biche    = connaitre le modele / systeme que l'on sollicite, pour apprivoiser son instantaneite.
Sanglier = cadrer le contexte, les pieces, le RAG, les sources et les skills a donner au systeme.
```

La Biche apprivoise celui qui ecoute.

Le Sanglier dompte ce qu'on lui donne.

La Biche protege l'intention.

Le Sanglier dompte le contexte.

## 1. Le recit mythologique

Le Sanglier d'Erymanthe est une bete sauvage.

Il charge, ravage, surgit brutalement.

Hercule ne doit pas seulement le tuer.

Il doit le capturer vivant.

Dans le recit, Hercule ne le combat pas frontalement dans son propre desordre.

Il le poursuit, l'epuise, le force a entrer dans un terrain ou sa puissance devient saisissable.

L'image importante est celle du ralentissement.

Mais ce ralentissement n'est pas passif.

Hercule ralentit la bete pour reprendre la direction du combat.

Le Sanglier conserve sa force, mais sa course cesse de dicter les conditions du combat.

Hercule ne nie pas le chaos.

Il ne laisse pas non plus le chaos commander.

Il cree un terrain ou le chaos devient orientable, cadrable et travaillable.

## 2. Les themes profonds

Le Sanglier parle de la matiere brute.

Un dossier reel n'arrive presque jamais propre.

Il arrive sous forme de fragments :

```text
mails
plans
photos
devis
captures
notes
versions
anciens echanges
demandes client
contraintes reglementaires
pieces manquantes
hypotheses
contradictions
urgences
souvenirs de reunion
elements valides
elements perimes
```

Ce n'est pas encore un contexte.

C'est une charge.

Philosophiquement, le Sanglier pose la question du passage de la matiere au cadre.

Une masse d'informations n'est pas encore un probleme formule.

Psychologiquement, il parle de l'urgence : quand le dossier charge, on veut souvent demander tres vite une synthese, une reponse ou une decision.

Le ralentissement est alors contre-intuitif.

Il donne l'impression de perdre du temps, alors qu'il permet de reprendre la direction du travail.

Sociologiquement, il parle des organisations documentaires reelles : dossiers partages, mails, plateformes, Knowledge Bases, pieces obsoletes, versions contradictoires, notes orales et responsabilites diffuses.

Epistemologiquement, il rappelle qu'une information n'a pas de valeur sans statut.

Un fait, une hypothese, une decision, une ancienne version, une demande client et un risque ne doivent pas entrer dans la reponse avec le meme poids.

## 3. Transposition IA

Le Sanglier correspond au moment ou l'on decide ce que l'on donne a l'IA.

Pas le modele.

Pas encore la sortie.

La matiere d'entree.

Cela inclut :

```text
quels documents injecter
quels documents exclure
quelle Knowledge Base activer
quel RAG utiliser
quel nombre de chunks recuperer
quel seuil de similarite accepter
quelles sources font foi
quelles sources sont provisoires
quelles sources sont obsoletes
quelles versions sont contradictoires
quelles skills sont pertinentes
quelles skills sont a eviter
quels faits sont etablis
quelles hypotheses restent ouvertes
quels risques doivent etre remontes
quel hors perimetre doit etre protege
```

Le piege est de croire que plus on donne de contexte, mieux l'IA repond.

C'est faux.

Trop peu de contexte appauvrit.

Trop de contexte pollue.

Un mauvais contexte oriente.

Un contexte contradictoire non declare fabrique une synthese trompeuse.

Un RAG trop large ramene du bruit.

Un RAG trop etroit rate les pieces decisives.

Une skill mal choisie transforme le probleme avant meme de le traiter.

Le Sanglier n'est donc pas donner du contexte.

C'est constituer un contexte.

Et constituer un contexte, c'est ralentir pour mieux diriger : choisir l'entree, le statut, le perimetre, la source, l'exclusion et le type de traitement attendu.

## 4. Le piege

Le piege du Sanglier est la clarte prematuree.

On verse la matiere brute dans le systeme :

```text
resume-moi ca
fais une synthese
prepare une reponse
dis-moi quoi faire
classe les informations
```

L'IA repond avec ordre.

Mais elle peut avoir melange :

```text
fait constate
hypothese
ancienne version
element valide
souhait client
contrainte reelle
contrainte supposee
risque juridique
urgence apparente
decision prise
decision a prendre
```

La reponse est lisible.

Mais le contexte n'etait pas gouverne.

C'est le Sanglier qui charge encore sous une belle forme.

```text
L'IA peut donner une forme au chaos
avant que le chaos soit compris.
```

```text
Une reponse claire peut naitre
d'un contexte mal dresse.
```

```text
Ralentir le dossier,
ce n'est pas ralentir le travail.
C'est reprendre la main sur sa direction.
```

## 5. Difference avec la Biche

La Biche concernait le systeme :

```text
Quel systeme ecoute ?
Comment reagit-il ?
Quelle vitesse impose-t-il ?
Quels parametres le rendent previsible ou instable ?
```

Le Sanglier concerne la matiere :

```text
Qu'est-ce que je lui donne ?
Dans quel ordre ?
Avec quel statut ?
Avec quelles exclusions ?
Avec quelles sources ?
Avec quelles skills ?
Avec quel perimetre ?
```

La Biche apprivoise celui qui ecoute.

Le Sanglier dompte ce qu'on lui donne.

## 6. Discipline active

Avant de demander une production a l'IA, il faut forcer une fiche de cadrage.

Ne pas commencer par :

```text
Voici tout le dossier, resume.
```

Commencer par :

```text
Avant de repondre, classe les elements en :
faits etablis,
hypotheses,
documents valides,
documents provisoires,
documents obsoletes,
contradictions,
pieces manquantes,
risques,
decisions deja prises,
decisions a prendre,
hors perimetre.

Ne produis pas encore le livrable.
Cadre d'abord le contexte.
```

Ce geste empeche l'IA de transformer immediatement un amas documentaire en recit plausible.

Dans une logique Pantheon :

```text
information != contexte
source != preuve
synthese != cadrage
RAG != verite
skill != pertinence automatique
fait != hypothese
demande != decision
urgence != priorite
ralentir != retarder
```

Ralentir signifie ici : imposer un ordre de lecture, un statut aux pieces, un perimetre aux sources et une direction au traitement.

## 7. Exemple concret

Un dossier chantier contient :

```text
3 devis
2 anciens plans
1 mail client inquiet
des photos de desordre
un compte rendu ancien
un message d'entreprise
une note orale non confirmee
une contrainte reglementaire incertaine
```

Prompt faible :

```text
Fais-moi une synthese et propose une reponse au client.
```

Risque : l'IA produit une note propre, mais elle melange les versions, donne trop de poids a un mail recent, oublie qu'un devis est obsolete, transforme une hypothese en fait ou donne une conclusion prematuree.

Prompt Sanglier :

```text
Ne redige pas encore de reponse.

Classe d'abord les elements du dossier :
1. faits etablis
2. hypotheses
3. documents valides
4. documents obsoletes ou incertains
5. contradictions
6. pieces manquantes
7. risques
8. decisions prises
9. decisions a prendre
10. elements hors perimetre

Ensuite seulement, propose le cadre de reponse.
```

On ne demande pas encore une sortie.

On ralentit pour mieux diriger.

On cree le terrain ou la sortie pourra etre fiable.

## 9. Cartel explicatif

```text
SANGLIER D'ERYMANTHE — Dompter le contexte

Le Sanglier d'Erymanthe est une force sauvage.
Il charge, ravage, echappe a la prise directe.
Hercule ne le combat pas dans son propre desordre.
Il le poursuit, le ralentit, le force a entrer dans un terrain ou sa puissance devient saisissable.

Avec l'IA, cette epreuve correspond au dossier brut.

Mails, plans, photos, devis, sources, RAG, versions, notes, skills, hypotheses, contradictions : tout cela n'est pas encore un contexte.
C'est une matiere en mouvement.

L'IA peut donner tres vite une forme claire a cette matiere.
Mais cette clarte peut etre prematuree.

Le danger n'est pas seulement d'avoir trop d'informations.
Le danger est de laisser l'IA organiser un chaos dont les statuts n'ont pas ete cadres.

Ralentir ne signifie pas retarder.
Cela signifie reprendre la direction : decider ce qui entre, ce qui reste dehors, ce qui fait foi, ce qui est incertain, ce qui manque, ce qui est hors perimetre et quelles skills peuvent etre utilisees.

Garde-fou :
avant toute production, constituer le contexte avant de demander la synthese.

Phrase a retenir :
Un dossier brut n'est pas encore un contexte.
```
