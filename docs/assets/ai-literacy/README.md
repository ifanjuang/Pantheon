# AI Literacy Assets

Status: support documentaire, non canonique, non executable.

Ce dossier rassemble les notes pedagogiques destinees aux supports Ulysse / Hercule sur l'usage de l'IA.

Il ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable, aucune politique d'approbation et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Points d'entree recommandes

### Ulysse

Pour la partie Ulysse, le point d'entree editorial principal est :

- `ulysse_reconciled_longform.md` : version longue reconciliee du corpus Ulysse, integrant la preface theorique, l'introduction, les dix escales stabilisees, la conclusion et la table finale de mediation.

Ce fichier doit etre utilise en priorite pour :

- article long ;
- livret pedagogique ;
- cartels explicatifs ;
- support de mediation ;
- base de reconciliation avant poster ou version HTML.

Pour une planche visuelle autonome Ulysse, utiliser :

- `ulysse_poster_distillation.md` : distillation poster pour une planche Ulysse seule, avec titre, sous-titre, phrase centrale, dix escales, cartel, direction artistique et prompts image.

Les autres fichiers Ulysse restent conserves comme sources de recherche, matrices courtes ou fiches detaillees.

Ils ne sont pas supprimes, car ils contiennent des formulations, variantes et traces editoriales utiles.

### Hercule

Pour la partie Hercule, les deux points d'entree editoriaux sont :

- `hercule_ai_discipline.md` : fichier maitre court, stabilisant la sequence des douze epreuves, les plaques, les maximes, les distinctions et les limites doctrinales ;
- `hercule_reconciliation_matrix.md` : matrice de reconciliation, utile pour verifier les registres, les formules et les renvois vers les fiches longues.

Pour une planche visuelle autonome Hercule, utiliser :

- `hercule_poster_distillation.md` : distillation poster impact pour une planche Hercule seule, avec phrase centrale, douze gestes lisibles, cartels, direction artistique et prompts image.

Les douze fiches longues Hercule sont maintenant disponibles.

Elles doivent etre utilisees comme supports de developpement editorial, de cartel explicatif, de livret pedagogique ou de scenographie visuelle.

Elles ne constituent pas une doctrine canonique Pantheon.

Elles ne creent aucun workflow executable.

### Diptyque Ulysse / Hercule

Pour articuler les deux routes, le point d'entree est :

- `ulysse_hercule_diptych_matrix.md` : matrice editoriale reliant les pieges detectes par Ulysse aux disciplines instituees par Hercule.

Cette matrice doit etre utilisee pour :

- construire une affiche diptyque ;
- preparer un livret Ulysse / Hercule ;
- concevoir une version HTML cliquable ;
- formuler des cartels transversaux ;
- maintenir la distinction entre perception critique et discipline active.

Elle ne remplace ni les fiches Ulysse, ni les fiches Hercule.

## Regle de reconciliation

Ne pas supprimer les fichiers de recherche tant que leur contenu n'a pas ete explicitement absorbe, verifie ou archive.

La reconciliation doit suivre cet ordre :

```text
1. Stabiliser la version longue reconciliee.
2. Identifier les formulations utiles restantes dans les fichiers sources.
3. Integrer ou ecarter explicitement ces formulations.
4. Marquer les anciens fichiers comme sources historiques ou les deplacer dans une archive dediee.
5. Ne jamais presenter une note de recherche comme une doctrine canonique Pantheon.
```

Pour Hercule, la reconciliation doit conserver la distinction suivante :

```text
hercule_ai_discipline.md        = carte maitre courte
hercule_reconciliation_matrix.md = controle des plaques et registres
*_scene_card.md                 = developpement long par epreuve
hercule_poster_distillation.md  = planche visuelle impact, non canonique
```

Le fichier maitre ne doit pas redevenir un doublon integral des fiches longues.

Les fiches longues ne doivent pas redefinir la doctrine Pantheon.

Pour le diptyque, la reconciliation doit conserver la distinction suivante :

```text
Ulysse  = reconnaitre les pieges
Hercule = instituer les gestes
Pantheon = gouverner les statuts
```

La matrice diptyque ne doit pas imposer une correspondance numerique artificielle entre dix escales et douze travaux.

## Statut editorial

Ces documents servent a produire :

- affiches pedagogiques ;
- diptyques Ulysse / Hercule ;
- cartels explicatifs ;
- supports HTML cliquables ;
- livrets ou notes de mediation.

Ils doivent rester distingues de la gouvernance canonique Pantheon.

Une metaphore aide a voir un phenomene.

Elle ne remplace ni l'enquete, ni la source, ni la preuve, ni le jugement professionnel.

## Methode de travail

Pour chaque lieu d'Ulysse ou epreuve d'Hercule, la fiche doit suivre ce parcours :

```text
recit mythologique
-> themes philosophiques, psychologiques, sociologiques et epistemologiques
-> transposition IA
-> piege ou force
-> exemple concret
-> garde-fou
-> formule affiche
-> cartel explicatif
```

Le but n'est pas d'illustrer l'IA par la mythologie de facon decorative.

Le but est de faire apparaitre les tensions reelles de l'usage : attention, desir, jugement, preuve, responsabilite, memoire, transmission et decision.

## Limite doctrinale

Ces supports restent documentaires.

Ils ne creent pas :

- agent runtime ;
- execution engine ;
- tool runtime ;
- provider router ;
- scheduler ;
- queue ;
- message bus ;
- memoire auto-promue ;
- workflow runtime cache ;
- approval automatique.

Ils servent a voir, formuler et transmettre les tensions.
