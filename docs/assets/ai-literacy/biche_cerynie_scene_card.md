# Biche de Cerynie — formuler l'intention

Status: support documentaire, non canonique, non executable.

Portee : fiche detaillee pour les diptyques pedagogiques Ulysse / Hercule.

Cette fiche complete `hercule_ai_discipline.md` et devra etre integree a une future version longue reconciliee du corpus Hercule.

Elle ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Repartition avec les epreuves voisines

```text
Lion   = la puissance doit etre eprouvee.
Hydre  = les possibles doivent etre explores puis tranches.
Biche  = l'intention doit etre formulee sans etre abimee.
Sanglier = le chaos doit etre cadre.
```

La Biche se situe avant le prompt efficace.

Elle ne parle pas encore du dossier brut, comme le Sanglier.

Elle parle du moment ou l'intention est encore fragile, tacite, rapide, difficile a saisir.

## Formule de recherche

```text
BICHE DE CERYNIE — Formuler l'intention.

Avant de prompter,
il faut savoir

C'est une forme juste,
elegante,

au contexte,
aux outils,

Une demande juste
commence avant la requete.
```

## 1. Le recit mythologique

La Biche de Cerynie est une creature sacree.

Elle est associee a Artemis.

Elle est rapide, insaisissable, delicate.

Hercule doit la capturer vivante.

Il ne doit pas la tuer.

Il ne doit pas la brutaliser.

Selon les versions, il la poursuit longtemps, parfois pendant une annee entiere.

Il doit attendre le bon moment.

Il doit l'atteindre sans detruire ce qui fait sa valeur.

Cette epreuve est donc tres differente des premieres.

Le Lion exige l'affrontement.

L'Hydre exige la methode de fermeture.

La Biche exige la precision sans violence.

Le succes n'est pas de posseder un objet mort.

Le succes est de saisir vivant ce qui pourrait etre abime par la capture.

## 2. Themes profonds

La Biche parle de l'intention fine.

Dans les metiers a responsabilite, on ne commence pas toujours par une consigne claire.

On commence par une intuition :

```text
un malaise ;
une direction ;
une prudence ;
un ton a tenir ;
un risque a ne pas ouvrir ;
une nuance a conserver ;
un destinataire a respecter ;
un niveau d'engagement a ne pas depasser ;
une idee que l'on n'arrive pas encore a formuler.
```

Cette intention est fragile.

Si on la force trop vite dans un prompt lourd, elle se deforme.

Si on la laisse trop vague, l'IA remplit les blancs a sa place.

La Biche enseigne donc la formulation ajustee.

```text
Il faut saisir l'intention
sans la reduire.
```

## 3. Transposition IA

Un bon usage de l'IA ne commence pas par une technique de prompt.

Il commence par une clarification de l'intention.

Avant de demander a l'IA de produire, il faut savoir :

```text
ce que je cherche vraiment ;
ce que je refuse de perdre ;
ce qui doit rester prudent ;
ce qui doit etre explore ;
ce qui doit etre exclu ;
le niveau de detail attendu ;
le destinataire ;
le niveau d'autorite ;
le statut de la sortie ;
le modele utilise ;
le contexte deja injecte ;
les outils disponibles ;
les risques d'action ou de transmission.
```

Le prompt ne doit pas etre une incantation.

Il doit etre une capture juste de l'intention.

## 4. Connaitre le modele et le systeme

La Biche ne se capture pas sans connaitre sa vitesse.

Avec l'IA, formuler l'intention suppose aussi de connaitre le systeme auquel on parle.

Un prompt juste depend de :

```text
modele utilise ;
taille du contexte ;
system prompt ;
temperature ;
retrieval ou RAG active ;
Knowledge Base disponible ;
skills ou outils accessibles ;
mode agentique ou non ;
connecteurs actifs ;
droits de chercher sur internet ;
droits d'agir ;
regles de memoire ;
style de sortie attendu.
```

La meme intention ne se formule pas pareil selon le modele, les outils et le contexte.

Un modele tres creatif demandera un cadrage different d'un modele tres analytique.

Un systeme avec outils d'action exige des bornes.

Un systeme avec RAG exige une precision sur les sources mobilisables.

Un systeme agentique exige des criteres d'arret.

```text
Une intention juste
change de forme
selon le systeme qui la recoit.
```

## 5. Prompt elegant, leger, optimise, adapte

La Biche ne demande pas un filet lourd.

Elle demande une prise fine.

Le prompt efficace n'est pas toujours le prompt le plus long.

Il peut etre court, mais bien oriente.

Il peut etre detaille, mais seulement sur les conditions utiles.

Il doit eviter deux erreurs :

```text
prompt pauvre : l'IA invente le cadre ;
prompt surcharge : l'intention se perd dans les contraintes.
```

Un prompt juste contient assez pour orienter, mais pas assez pour etouffer.

```text
Le bon prompt
ne charge pas l'IA de tout.
Il lui donne la bonne prise.
```

## 6. La capture vivante

La Biche doit etre capturee vivante.

C'est le coeur de l'epreuve.

Avec l'IA, cela signifie : formuler sans tuer l'intention.

Exemples de destruction de l'intention :

```text
transformer une intuition en cahier des charges trop rigide ;
transformer une nuance en instruction binaire ;
transformer une prudence en interdiction totale ;
transformer une exploration en conclusion attendue ;
transformer un ton en style artificiel ;
transformer une responsabilite en automatisme.
```

La Biche demande de garder vivant ce qui est encore en train de se former.

```text
Une intention trop tot rigidifiee
cesse parfois d'etre juste.
```

## 7. Le piege

Le piege de la Biche est la precipitation.

On prompt trop vite.

On demande une sortie avant d'avoir compris la demande.

On donne beaucoup de contexte sans avoir defini ce qu'il doit faire.

On demande a l'IA de clarifier l'intention a notre place, puis on confond sa reformulation avec notre volonte.

Le risque est subtil : l'IA peut tres bien formuler une intention qui semble meilleure que la notre, mais qui a perdu le tact initial.

```text
L'IA peut rendre claire
une intention qu'elle a deja deplacee.
```

## 8. Difference avec Hydre et Sanglier

L'Hydre traite les options qui proliferent apres ouverture.

La Biche traite l'intention avant la formulation.

Le Sanglier traitera le chaos d'un dossier reel a cadrer.

```text
Hydre    : que faire des pistes qui se multiplient ?
Biche    : quelle intention faut-il saisir avant la requete ?
Sanglier : comment cadrer le desordre du reel ?
```

## 9. Discipline active

Avant tout prompt important, remplir une fiche d'intention :

```text
objectif reel
ce qu'il ne faut pas perdre
ce qu'il ne faut pas faire
niveau d'engagement
destinataire
ton
statut de sortie : exploration / brouillon / candidat / livrable
sources autorisees
outils autorises
memoire autorisee ou interdite
critere de reussite
critere d'arret
```

Puis formuler le prompt en trois couches :

```text
1. intention ;
2. conditions ;
3. sortie attendue.
```

Dans une logique Pantheon :

```text
prompt long != prompt juste
contexte abondant != intention claire
reformulation IA != volonte humaine
systeme agentique != mandat implicite
outil disponible != autorisation
sortie claire != intention preservee
```

## 10. Exemple concret

### Prompt faible

```text
Redige-moi une reponse professionnelle.
```

Risque : l'IA choisit le ton, le niveau d'engagement et parfois le fond.

### Prompt Biche

```text
Avant de rediger, aide-moi a clarifier l'intention.
Je veux une reponse professionnelle mais prudente.
Je ne veux pas reconnaitre une responsabilite non etablie.
Je veux rester factuel, ferme et ouvert a une verification contradictoire.
La sortie doit etre un brouillon, pas un engagement final.
Propose d'abord l'intention en 3 lignes, puis seulement ensuite le mail.
```

### Prompt systeme adapte

```text
Tu dois m'aider a formuler une intention avant production.
Ne produis pas encore le livrable.
Pose les distinctions necessaires : objectif, destinataire, niveau d'engagement, risque, statut de sortie, points a exclure.
Ensuite seulement, propose un prompt court et adapte au modele.
```

## 12. Cartel explicatif

```text
BICHE DE CERYNIE — Formuler l'intention

La Biche est rapide, sacree et fragile. Hercule doit la capturer vivante, sans l'abimer. Le travail demande precision, patience et retenue.

Avec l'IA, cette epreuve correspond au moment avant le prompt. L'intention est souvent tacite : ce que l'on cherche vraiment, ce que l'on ne veut pas perdre, le niveau de prudence, le destinataire, le risque et le statut de la sortie.

Le danger est de prompter trop vite, de laisser l'IA remplir l'intention, ou de l'ecraser sous un prompt trop lourd.

Garde-fou :
clarifier l'intention avant la requete, connaitre le modele et le systeme, puis formuler un prompt adapte, elegant, leger et suffisamment borne.

Phrase a retenir :
Une demande juste commence avant la requete.
```
