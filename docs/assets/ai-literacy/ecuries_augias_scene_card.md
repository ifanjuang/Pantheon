# Ecuries d'Augias — assainir la matiere

Status: support documentaire, non canonique, non executable.

Portee : fiche detaillee pour les diptyques pedagogiques Ulysse / Hercule.

Cette fiche complete `hercule_ai_discipline.md` et devra etre integree a une future version longue reconciliee du corpus Hercule.

Elle ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

```text

```

## 1. Le recit mythologique

Les Ecuries d'Augias sont remplies d'une salete accumulee depuis longtemps.

Augias possede d'immenses troupeaux.

Les ecuries n'ont pas ete nettoyees depuis des annees.

La tache semble impossible par les moyens ordinaires.

Hercule ne nettoie pas pelle par pelle.

Il detourne le cours de deux fleuves pour faire traverser les ecuries par une puissance de lavage.

Le travail est spectaculaire parce qu'il change d'echelle.

La salete accumulee n'est pas traitee fragment par fragment.

Elle est evacuee par une circulation nouvelle.

Mais le point important n'est pas seulement le nettoyage.

C'est la reconnaissance que la matiere doit etre assainie avant que le lieu puisse redevenir habitable et utile.

## 2. Themes profonds

Les Ecuries parlent de l'accumulation.

La salete n'est pas un accident ponctuel.

Elle est le produit du temps, de la negligence, de l'absence de tri, de l'absence de statut.

Avec l'IA, cette salete est documentaire et cognitive :

```text
fichiers obsoletes ;
doublons ;
versions contradictoires ;
notes sans date ;
sources faibles ;
exports incomplets ;
captures floues ;
corpus melanges ;
donnees sensibles inutiles ;
anciennes decisions ;
hypotheses non marquees ;
brouillons confondus avec valides.
```

L'IA peut faire semblant de nettoyer en produisant une reponse propre.

Mais une sortie bien ecrite ne transforme pas une matiere mauvaise en matiere fiable.

```text
Une matiere trouble
donne souvent
une clarte trompeuse.
```

## 3. Transposition IA

Avant de faire travailler l'IA sur un corpus, il faut verifier la matiere.

Ce qui est disponible n'est pas forcement utilisable.

Ce qui est dans le dossier n'est pas forcement a transmettre au modele.

Ce qui est lisible n'est pas forcement valide.

Ce qui est ancien n'est pas forcement obsolete, mais doit etre date.

Ce qui est nouveau n'est pas forcement plus juste.

Les Ecuries demandent donc une hygiene epistemique.

```text
matiere disponible != matiere utilisable
```

## 4. Detourner les fleuves

Hercule ne nettoie pas a la main.

Il cree un flux qui traverse la salete accumulee.

Avec l'IA, detourner les fleuves signifie installer une methode de nettoyage :

```text
nommer ;
dater ;
dedoublonner ;
classer ;
exclure ;
anonymiser ;
hierarchiser ;
marquer les statuts ;
isoler les contradictions ;
separer les sources ;
separer les preuves ;
separer les brouillons ;
retirer les donnees sensibles inutiles.
```

Ce n'est pas une production.

C'est une preparation.

L'IA peut aider a ce nettoyage, mais elle ne doit pas canoniser ce qu'elle trie.

Elle peut proposer des classifications, des exclusions candidates, des regroupements.

Mais le statut final doit rester gouverne.

## 5. Salete documentaire et salete conceptuelle

Les Ecuries ne concernent pas seulement les fichiers.

Elles concernent aussi les idees sales.

Une idee sale peut etre :

```text
un concept mal defini ;
un terme utilise dans deux sens differents ;
une hypothese devenue habitude ;
un precedent non verifie ;
une source repetee sans controle ;
un argument d'autorite ;
une confusion entre exemple et regle ;
une decision ancienne reutilisee hors contexte.
```

Si ces elements entrent dans le prompt ou le RAG, l'IA peut les amplifier.

```text
L'IA ne nettoie pas toujours la confusion.
Elle peut lui donner une meilleure syntaxe.
```

## 6. Le piege

Le piege des Ecuries est la proprete de surface.

Une reponse IA peut etre lisible, elegante, structuree, convaincante.

Mais la question essentielle est : avec quelle matiere a-t-elle travaille ?

Si la matiere est mauvaise, la sortie propre est dangereuse.

Elle rend la salete moins visible.

```text
La proprete de la reponse
ne lave pas
la salete du corpus.
```

## 7. Difference avec Sanglier et Oiseaux

Le Sanglier cadre le dossier brut.

Les Ecuries assainissent la matiere.

Les Oiseaux discernent le signal dans l'environnement informationnel.

```text
Sanglier : quel cadre rend le reel praticable ?
Ecuries  : quelle matiere est assez saine pour etre utilisee ?
Oiseaux  : qu'est-ce qui merite attention dans le bruit ?
```

## 8. Discipline active

Avant ingestion, analyse ou production, preparer le corpus :

```text
inventaire ;
dates ;
versions ;
doublons ;
statuts ;
sources primaires ;
sources secondaires ;
brouillons ;
valides ;
contradictions ;
perimes ;
sensibles ;
a exclure ;
a anonymiser ;
a verifier.
```

Demander a l'IA de produire une table de hygiene documentaire, pas directement une synthese.

Dans une logique Pantheon :

```text
corpus disponible != corpus gouverne
proprete de style != proprete de matiere
source faible != preuve
brouillon != valide
ancienne version != canon
tri automatique != canonisation
nettoyage candidat != validation documentaire
```

## 9. Exemple concret

### Prompt faible

```text
Voici tous les documents. Fais une synthese.
```

Risque : l'IA produit une synthese claire a partir d'un corpus mal qualifie.

### Prompt Ecuries

```text
Ne fais pas encore de synthese.
Commence par assainir la matiere documentaire.
Classe chaque element en :
1. source primaire ;
2. source secondaire ;
3. brouillon ;
4. version obsolete ;
5. doublon ;
6. contradiction ;
7. donnee sensible inutile ;
8. element a verifier ;
9. element utilisable.

Explique les raisons du classement.
Ne considere rien comme valide sans statut explicite.
```

### Nettoyage conceptuel

```text
Avant de produire, liste les termes ambigus, les hypotheses implicites, les confusions possibles et les decisions anciennes qui pourraient etre reutilisees hors contexte.
```

