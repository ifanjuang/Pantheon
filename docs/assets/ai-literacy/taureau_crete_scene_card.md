# Taureau de Crete — diriger par les conditions d'action

Status: support documentaire, non canonique, non executable.

Portee : fiche detaillee pour les diptyques pedagogiques Ulysse / Hercule.

Cette fiche complete `hercule_ai_discipline.md` et devra etre integree a une future version longue reconciliee du corpus Hercule.

Elle ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Repartition avec les epreuves voisines

Cette fiche distingue trois registres proches mais differents :

```text
Lion     = eprouver la puissance du modele dans le reel metier.
Sanglier = cadrer la matiere donnee au systeme.
Taureau  = diriger l'action par ses conditions.
```

Le Lion demande : cette force est-elle reelle ?

Le Sanglier demande : cette matiere est-elle gouvernable ?

Le Taureau demande : cette action est-elle orientee, autorisee, tracee et arretee au bon seuil ?

## 1. Le recit mythologique

Le Taureau de Crete arrive d'abord comme un signe.

Minos veut affirmer son droit a regner sur la Crete.

Il demande a Poseidon de lui envoyer un taureau venu de la mer.

Le dieu accorde le signe, mais la force recue devait etre rendue : le taureau devait etre sacrifie a Poseidon.

Minos garde le taureau, trop beau, trop puissant, trop precieux.

Il substitue un autre animal.

La force perd alors sa destination.

Ce qui devait etre consacre devient possession.

Ce qui devait etre rendu devient puissance conservee.

L'ordre se rompt.

Le taureau devient ravageur.

Il traverse la Crete, devaste les terres, deracine les cultures et echappe au controle.

Hercule est envoye pour le capturer vivant.

Il ne s'agit pas de comprendre le taureau de loin.

Il ne s'agit pas non plus de le detruire.

Hercule le saisit, le maitrise, le rend transportable et le ramene.

Le geste central est donc : rendre gouvernable une puissance qui peut entrer dans le monde.

## 2. Les themes profonds

Le Taureau parle du passage a l'acte.

Tant que l'IA parle, le risque reste principalement cognitif, documentaire ou interpretatif.

Des qu'elle peut agir, le risque devient operationnel.

Ce passage change tout.

Une mauvaise reponse peut etre corrigee.

Une mauvaise action peut produire des effets.

Le Taureau ne represente donc pas une force a neutraliser.

Il represente une force a orienter.

La question n'est pas seulement :

```text
Que dit l'IA ?
```

La question devient :

```text
Que peut-elle faire ?
Pour quelle finalite ?
Sur quel perimetre ?
Avec quelle validation ?
Sous quelle trace ?
Jusqu'a quel point d'arret ?
```

## 3. La force et sa destination

La faute de Minos est decisive.

Il ne manque pas de puissance.

Il manque de juste destination.

La force recue n'est pas rendue au bon ordre.

Elle est gardee, detournee, possedee.

Avec l'IA, le meme risque apparait lorsqu'un outil disponible devient implicitement un droit general.

Un systeme peut chercher sur Internet.

Il peut lire un agenda.

Il peut proposer une modification de repo.

Il peut ouvrir une PR.

Il peut corriger un fichier.

Il peut preparer un email.

Il peut appeler une API.

Mais la disponibilite d'un outil ne definit pas encore la justesse de son usage.

```text
Un outil disponible
n'est pas un droit general.
```

```text
Une force sans destination
devient une charge.
```

## 4. Transposition IA

Le Taureau commence lorsque l'IA peut :

```text
chercher en ligne
lire un calendrier
creer un evenement
inviter quelqu'un
modifier un fichier
appliquer un patch
committer
ouvrir une pull request
envoyer un email
publier un contenu
supprimer une donnee
appeler une API
executer du code
transmettre une piece
classer une information
```

Ces capacites sont utiles.

Elles ne sont pas des fautes.

Mais elles doivent recevoir des conditions d'action.

Par exemple :

```text
Chercher sur Internet si la question exige une donnee actuelle,
avec sources citees et distinction preuve / hypothese / interpretation.

Lire l'agenda pour proposer des creneaux,
mais ne pas creer ni modifier d'evenement sans validation explicite.

Corriger le repo dans le perimetre documentaire autorise,
mais demander confirmation pour les schemas, tests, operations, platform, Docker ou fichiers sensibles.

Preparer un patch candidat,
mais ne pas le presenter comme implemente tant qu'il n'est pas applique et verifie.

Creer une memoire candidate,
mais ne jamais la promouvoir en memoire canonique sans decision gouvernee.
```

Le sujet n'est donc pas l'existence de l'outil.

Le sujet est le regime d'action qui l'accompagne.

## 5. Les trois regimes

Le Taureau impose de distinguer :

```text
repondre
preparer
agir
```

Repondre : produire une analyse, une hypothese, une suggestion, une explication.

Preparer : creer un brouillon, une proposition, un patch candidat, un email non envoye, une liste d'actions a valider.

Agir : envoyer, publier, modifier, supprimer, transmettre, executer, valider, reserver, deplacer, committer.

Chaque passage de regime augmente l'exigence de conditions.

Une sortie candidate ne doit pas devenir action par glissement.

```text
Repondre propose.
Preparer oriente.
Agir engage.
```

## 6. Le piege

Le piege du Taureau est la continuite apparente entre dire et faire.

Dans une interface, tout peut sembler fluide.

L'IA propose.

Puis elle execute.

Le changement de regime peut devenir invisible.

Pourtant, ce n'est plus le meme monde.

```text
Une phrase peut etre une hypothese.
Un bouton peut etre un acte.
```

Le danger n'est pas seulement l'erreur.

Le danger est le declenchement premature : une reponse candidate, parce qu'elle semble bonne, devient envoi, modification, publication, suppression ou execution.

C'est le Taureau qui charge.

```text
Une sortie candidate
ne doit pas devenir action
par glissement.
```

## 7. Conditions d'action

Diriger le Taureau, c'est definir les conditions de son action.

Toute capacite d'action doit recevoir :

```text
direction
finalite
perimetre
droit
limite
validation
trace
journal
reversibilite quand possible
point d'arret
responsable humain
seuil d'escalade
```

Dans une logique Pantheon :

```text
reponse != action
brouillon != envoi
patch candidat != modification appliquee
classification != memoire canonique
outil disponible != outil autorise
capacite technique != droit d'action
sortie candidate != livrable valide
```

Gouverner l'action, c'est etablir les conditions dans lesquelles la force peut agir juste.

## 8. Faux controle et faux sacrifice

La legende permet aussi une lecture plus subtile.

Minos ne refuse pas explicitement Poseidon.

Il accomplit un geste de remplacement : il sacrifie un autre animal et garde le vrai taureau.

Avec l'IA, le faux sacrifice apparait quand une organisation donne une apparence de controle sans gouverner reellement le droit d'action.

Exemples :

```text
un bouton de validation trop general
une permission accordee pour tout un outil sans perimetre
un mode agentique active sans seuil d'arret
un acces repo ouvert alors que seuls les fichiers documentaires sont autorises
un outil calendrier qui peut creer un evenement alors qu'il devait seulement proposer un creneau
un brouillon qui peut etre envoye dans la meme continuite que sa generation
```

Le faux controle garde la force intacte tout en donnant l'impression qu'elle est encadree.

```text
Une bride vague
n'est pas encore une condition d'action.
```

## 9. Minotaures operationnels

La consequence indirecte du Taureau mal consacre est le Minotaure.

Cette piste est utile pour l'IA.

Une action mal gouvernee ne produit pas seulement une erreur ponctuelle.

Elle peut produire des objets hybrides :

```text
document semi-valide
memoire semi-canonique
email semi-engageant
workflow semi-autonome
decision semi-humaine
preuve semi-verifiee
action semi-assumee
```

Ces objets deviennent des labyrinthes operationnels.

On ne sait plus s'ils sont brouillon, preuve, decision, livrable, action ou memoire.

```text
Le labyrinthe commence
quand on ne sait plus si une sortie est
brouillon,
preuve,
decision,
action,
ou memoire.
```

## 10. Exemple concret

### Internet

Prompt faible :

```text
Cherche sur Internet et dis-moi quoi faire.
```

Prompt Taureau :

```text
Cherche uniquement pour verifier les informations susceptibles d'avoir change.
Cite les sources.
Distingue fait, interpretation et recommandation.
Ne conclus pas sans source primaire lorsque le risque est juridique, technique ou financier.
```

### Agenda

Prompt faible :

```text
Trouve un creneau et organise la reunion.
```

Prompt Taureau :

```text
Lis uniquement les disponibilites.
Propose trois creneaux.
Ne cree aucun evenement.
N'invite personne.
Attends validation humaine avant toute action calendrier.
```

### Repo

Prompt faible :

```text
Corrige le repo.
```

Prompt Taureau :

```text
Propose ou applique uniquement les corrections documentaires autorisees.
Ne touche pas aux schemas, tests, operations, platform, Docker, pyproject.toml ou fichiers sensibles sans confirmation.
Ajoute un ai_log apres intervention significative.
Verifie le diff reel apres commit.
Ne dis jamais implemente si c'est seulement documente.
```
