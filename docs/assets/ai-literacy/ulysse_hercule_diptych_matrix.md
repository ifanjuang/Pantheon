# Ulysse / Hercule — matrice de diptyque

Status: support documentaire, non canonique, non executable.

Portee : matrice editoriale pour articuler les deux corpus pedagogiques Ulysse et Hercule.

Ce fichier sert a preparer :

- affiches pedagogiques ;
- diptyques visuels ;
- livrets de mediation ;
- cartels explicatifs ;
- supports HTML cliquables ;
- narration publique du corpus IA literacy.

Il ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable, aucune politique d'approbation et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## These centrale

Ulysse et Hercule ne racontent pas la meme chose.

Ulysse reconnait les pieges.

Hercule institue les gestes.

Ulysse travaille la perception.

Hercule travaille la discipline.

Ulysse montre comment l'IA peut deformer notre rapport au travail, au desir, a l'attention, a la memoire, a la forme et au jugement.

Hercule montre comment tenir les forces de l'IA sans les reduire a la peur, au controle ou au refus.

```text
Ulysse detecte ce qui nous egare.
Hercule organise ce qui nous rend capables.
```

## Regle de composition

Ne pas forcer une correspondance numerique.

Ulysse contient dix escales.

Hercule contient douze travaux.

La matrice ne doit pas chercher une symetrie artificielle.

Elle doit faire apparaitre des tensions utiles :

```text
piege -> discipline
perception -> geste
seduction -> epreuve
abondance -> mesure
memoire confuse -> seuil
production fluide -> responsabilite
```

Le diptyque doit rester lisible :

```text
Ulysse = deceler les pieges.
Hercule = maitriser les pouvoirs.
```

## Formule directrice

```text
DECELER LES PIEGES. MAITRISER LES POUVOIRS.

Ulysse reconnait les egarements.
Hercule transforme les forces en disciplines.

Prouver avant de decider.
```

Variante plus professionnelle :

```text
Reconnaître ce qui nous trompe.
Organiser ce qui nous augmente.
Decider seulement ce qui peut etre prouve, porte et transmis.
```

## Trois lignes narratives possibles

### 1. Ligne professionnelle

```text
L'IA produit vite.
Ulysse apprend a ne pas croire trop vite.
Hercule apprend a ne pas agir trop vite.
Pantheon garde les statuts jusqu'a decision humaine.
```

Usage : README public, livret professionnel, introduction de conference.

### 2. Ligne epistemologique

```text
Ulysse travaille les conditions de perception.
Hercule travaille les conditions d'usage.
La preuve transforme une sortie en objet discutable.
La validation transforme un candidat en decision.
```

Usage : article long, mediation academique, table ronde.

### 3. Ligne visuelle

```text
A gauche : les pieges qui capturent le regard.
A droite : les epreuves qui forment le geste.
Au centre : prouver avant de decider.
```

Usage : poster, exposition, scenographie.

## Axes de lecture pour poster

### Axe 1 — Perception / discipline

```text
Ulysse : voir ce qui nous arrive.
Hercule : tenir ce que l'on declenche.
```

### Axe 2 — Piege / geste

```text
Un piege n'est pas seulement une erreur.
C'est une situation ou notre jugement est deplace.

Un geste n'est pas seulement une procedure.
C'est une condition d'usage qui rend la puissance assumable.
```

### Axe 3 — Seduction / responsabilite

```text
L'IA seduit par la forme, l'abondance, la vitesse et la coherence.
La responsabilite commence quand on demande : qu'est-ce que je peux prouver, porter et transmettre ?
```

### Axe 4 — Source / preuve / sortie / memoire

```text
Ulysse aide a ne pas croire trop vite.
Hercule aide a ne pas produire trop vite.
Pantheon aide a ne pas garder trop vite.
```

## Scenographie du diptyque

### Partie gauche — Ulysse

Ambiance : navigation, archipel, passages, iles, detours, signaux seduisants, seuils instables.

Fonction : montrer comment l'IA agit sur la perception.

Motifs possibles :

```text
mer de sorties possibles ;
iles de pieges ;
chants seduisants ;
portes poreuses ;
archives souterraines ;
retour vers Ithaque ;
fil de jugement.
```

### Partie droite — Hercule

Ambiance : ateliers, epreuves, seuils, forces canalisees, gestes, cadrages, outils gouvernes.

Fonction : montrer comment l'IA devient praticable sous conditions.

Motifs possibles :

```text
lion eprouve ;
hydre des hypotheses ;
biche de l'intention ;
sanglier du dossier brut ;
fleuve de nettoyage documentaire ;
oiseaux du bruit ;
taureau de l'action ;
juments de l'autonomie ;
ceinture du mandat ;
attelage des outils ;
pommes du livrable ;
cerbere de la memoire.
```

### Centre

Le centre ne doit pas etre decoratif.

Il doit etre la regle d'arbitrage :

```text
PROUVER AVANT DE DECIDER
```

Sous-formule :

```text
Une source n'est pas une preuve.
Une sortie n'est pas un livrable.
Un candidat n'est pas un valide.
Un usage ponctuel n'est pas un droit de demeure.
```

## Cartel court

```text
ULYSSE / HERCULE — IA ET JUGEMENT PROFESSIONNEL

Ulysse apprend a reconnaitre les pieges : abondance, seduction, regard unique, requete trop rapide, memoire confuse, porosite des espaces, sortie prise pour jugement.

Hercule apprend a tenir les forces : eprouver la puissance, explorer sans se perdre, formuler l'intention, cadrer le chaos, assainir la matiere, discerner le signal, diriger l'action, borner l'autonomie, legitimer la transmission, composer l'attelage, murir le livrable et garder les seuils du retour.

Le diptyque ne dit pas que l'IA doit etre refusee.

Il dit que la puissance doit rester sous preuve, statut, responsabilite et decision humaine.
```

## Anti-confusions

```text
Ulysse n'est pas la peur de l'IA.
Hercule n'est pas le controle brutal de l'IA.
Pantheon n'est pas un runtime agentique.
```

```text
Ulysse = perception critique.
Hercule = discipline active.
Pantheon = gouvernance des statuts.
```

## Limite doctrinale

Cette matrice est un outil editorial.

Elle ne cree pas :

- agent runtime ;
- execution engine ;
- tool runtime ;
- provider router ;
- scheduler ;
- queue ;
- message bus ;
- LangGraph central ;
- workflow runtime cache ;
- memoire auto-promue ;
- self-evolution ;
- plugin manager ;
- marketplace de skills ;
- approval automatique.

Elle aide a composer un support de mediation.

Elle ne remplace ni la preuve, ni la validation, ni le jugement professionnel.
