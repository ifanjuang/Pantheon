# Boeufs de Geryon — composer l'attelage

Status: support documentaire, non canonique, non executable.

Portee : fiche detaillee pour les diptyques pedagogiques Ulysse / Hercule.

Cette fiche complete `hercule_ai_discipline.md` et devra etre integree a une future version longue reconciliee du corpus Hercule.

Elle ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Repartition avec les epreuves voisines

Cette fiche distingue quatre seuils proches mais differents :

```text
Taureau  = l'action doit recevoir des conditions.
Juments  = l'autonomie doit recevoir un terme.
Ceinture = la transmission doit recevoir une legitimite.
Boeufs   = les forces doivent recevoir un attelage situe.
```

Le Taureau gouverne l'acte.

Les Juments gouvernent la duree.

La Ceinture gouverne la transmission.

Les Boeufs gouvernent l'agencement des forces dans un travail augmente.

## 1. Le recit mythologique

Les Boeufs de Geryon appartiennent a un etre monstrueux, souvent decrit avec trois corps ou trois troncs.

Ils vivent loin, aux confins occidentaux du monde connu, sur l'ile d'Erythie.

Le troupeau est garde.

Il ne suffit pas d'atteindre les boeufs.

Il faut franchir la distance, affronter les gardiens, vaincre Geryon, puis ramener le troupeau.

Cette epreuve n'est pas un duel simple.

C'est une epreuve de passage, de convoi et de conduite.

Hercule ne doit pas seulement vaincre.

Il doit conduire.

Le troupeau n'est pas une force unique.

C'est une multiplicite vivante, dispersable, difficile a ramener sans ordre.

Le geste central n'est donc pas seulement la conquete.

C'est l'attelage : faire avancer plusieurs forces sans qu'elles se dispersent.

## 2. Les themes profonds

Les Boeufs parlent de la cognition distribuee.

Le travail ne se fait plus dans une seule tete.

Il ne se fait pas non plus dans un seul outil.

Il circule entre humains, modeles, sources, documents, interfaces, procedures, outils, memoire, validations et livrables.

Cette distribution peut augmenter le travail.

Mais elle peut aussi diluer la responsabilite.

```text
Quand la cognition se distribue,
la responsabilite doit se preciser.
```

Le danger n'est donc pas seulement qu'une force agisse mal.

Le danger est que plusieurs forces agissent ensemble sans agencement clair.

```text
Sans attelage,
les forces augmentees
brouillent la responsabilite.
```

## 3. Transposition IA

Dans un travail IA reel, il n'y a pas seulement un humain face a un chatbot.

Il y a un convoi :

```text
un modele qui genere
des sources qui documentent
un RAG qui recupere
des fichiers qui cadrent
des outils qui agissent
des agents qui executent
une memoire qui conserve
des regles metier qui limitent
un humain qui decide
des validations qui stabilisent
un livrable qui sort
```

Chaque force peut tirer dans sa direction.

Le modele veut produire.

Le RAG ramene du contexte.

Les outils veulent agir.

Les agents veulent continuer.

La memoire veut retenir.

Les sources veulent faire autorite.

Le livrable veut devenir final.

L'humain peut croire que tout est aligne alors que chaque force tire ailleurs.

Le sujet des Boeufs est donc l'organisation du travail augmente.

Pas l'orchestration runtime.

Pas le swarm.

Pas l'automatisation cachee.

Mais l'agencement visible des roles, preuves, outils, memoires, validations et responsabilites.

## 4. Methode situee

Il n'existe pas un enchainement universel.

Un architecte, un avocat, un medecin, un chercheur, un developpeur, un syndic, un artisan ou un enseignant ne doivent pas organiser l'IA de la meme maniere.

Meme dans un meme metier, l'attelage change selon la situation :

```text
urgence
analyse
production
verification
decision
transmission
memoire
contentieux
client sensible
source incertaine
outil externe
risque reglementaire
livrable engageant
```

L'IA peut proposer une sequence plausible :

```text
chercher
classer
resumer
verifier
produire
corriger
transmettre
memoriser
```

Mais un enchainement plausible n'est pas encore une methode juste.

Parfois il faut chercher avant d'ecrire.

Parfois il faut cadrer avant de chercher.

Parfois il faut verifier avant de produire.

Parfois il faut demander une decision avant de continuer.

Parfois il faut produire seulement un brouillon.

Parfois il faut isoler les hypotheses avant toute synthese.

Parfois il faut refuser la transmission, la memoire ou l'action.

```text
Un enchainement coherent pour l'IA
peut etre incoherent pour le metier.
```

## 5. Correction progressive

L'avantage de l'IA est qu'elle peut ajuster sa methode lorsque l'humain corrige clairement ses enchainements.

Mais cette correction doit donner les raisons.

Dire seulement :

```text
ce n'est pas bon
```

ne suffit pas.

Il faut expliquer :

```text
pourquoi l'ordre est mauvais
quelle etape devait venir avant
quel risque etait ignore
quel statut etait confondu
quelle validation manquait
quel outil etait trop tot
quel livrable etait premature
quelle transmission etait illegitime
quelle memoire aurait ete dangereuse
```

Plus on corrige la methode en donnant les raisons, plus l'IA devient ajustee.

Mais elle ne doit pas conduire seule avant que l'attelage soit eprouve.

```text
L'attelage se gagne par correction,
pas par automatisme.
```

```text
On ne laisse pas conduire
ce qui n'a pas encore appris
la route du metier.
```

## 6. Le piege

Le piege des Boeufs est le travail augmente sans architecture de responsabilite.

On branche :

```text
un modele
un RAG
des fichiers
des outils
un agent
une memoire
un connecteur
une recherche web
une validation humaine
```

Puis on suppose que l'ensemble produit une intelligence coherente.

Mais l'addition des forces ne produit pas encore un jugement.

Sans attelage clair, on obtient :

```text
sources non hierarchisees
outils mal mandates
agents qui se chevauchent
memoire appelee hors perimetre
preuves melees aux hypotheses
sorties candidates prises pour livrables
responsabilite diluee
validation humaine reduite a un clic
```

```text
Multiplier les capacites
ne suffit pas a organiser le travail.
```

## 7. Difference avec Taureau, Juments et Ceinture

Le Taureau traite le passage a l'action :

```text
Que peut faire l'IA maintenant ?
Avec quelles conditions ?
```

Les Juments traitent l'autonomie dans la duree :

```text
Jusqu'ou l'IA peut-elle continuer seule ?
Quand doit-elle rendre la main ?
```

La Ceinture traite la legitimite de la circulation :

```text
Quels pouvoirs et quelles informations peuvent circuler ?
Vers qui ?
Pour quoi ?
Avec quel mandat ?
```

Les Boeufs traitent l'agencement des forces :

```text
Qui fait quoi,
avec quoi,
sous quel statut,
et qui repond du resultat ?
```

## 8. Discipline active

Avant de produire avec un systeme augmente, dessiner l'attelage :

```text
objectif
metier concerne
situation precise
niveau de risque
sources autorisees
RAG ou base documentaire mobilisee
outils autorises
agents ou profiles mobilises
role humain
role de verification
statut des sorties
statut des preuves
conditions d'action
conditions d'autonomie
conditions de transmission
conditions de memoire
livrable attendu
point de validation
responsable final
```

Questions pratiques :

```text
Qui cherche ?
Qui source ?
Qui reformule ?
Qui verifie ?
Qui agit ?
Qui conserve ?
Qui transmet ?
Qui valide ?
Qui decide ?
```

Dans une logique Pantheon :

```text
modele != responsable
agent != role Pantheon
profile Hermes != role Pantheon
source != preuve
RAG != contexte gouverne
outil disponible != droit d'action
memoire candidate != memoire canonique
sortie candidate != livrable valide
validation humaine != clic final vague
orchestration visible != runtime cache
```

## 9. Exemple concret

### Analyse de dossier professionnel

Prompt faible :

```text
Analyse ce dossier et produis la note finale.
```

Risque : le modele peut commencer par rediger, puis chercher de quoi soutenir sa synthese, melanger source et preuve, transformer une hypothese en conclusion et produire trop vite un livrable apparent.

Prompt Boeufs :

```text
Ne produis pas encore la note finale.

Propose d'abord l'attelage de travail adapte a ce dossier :
1. sources a lire ;
2. pieces a exclure ;
3. points a verifier ;
4. risques metier ;
5. role du modele ;
6. role des sources ;
7. outils eventuels ;
8. validations humaines ;
9. sortie candidate attendue ;
10. conditions avant livrable final.

Explique pourquoi cet enchainement est coherent avec le metier et le niveau de risque.
```

### Correction repo documentaire

Prompt faible :

```text
Corrige le repo.
```

Prompt Boeufs :

```text
Avant toute modification, propose l'attelage :
1. fichiers documentaires autorises ;
2. fichiers sensibles exclus ;
3. verification du diff ;
4. ai_log requis ;
5. statut documentaire seulement ;
6. points necessitant confirmation.

N'applique que les modifications compatibles avec ce perimetre.
```
