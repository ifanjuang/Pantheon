# Sanglier d'Erymanthe — cadrer le chaos

Status: support documentaire, non canonique, non executable.

Portee : fiche detaillee pour les diptyques pedagogiques Ulysse / Hercule.

Cette fiche complete `hercule_ai_discipline.md` et devra etre integree a une future version longue reconciliee du corpus Hercule.

Elle ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Repartition avec les epreuves voisines

```text
Biche     = l'intention doit etre formulee sans etre abimee.
Sanglier  = le chaos doit etre rendu praticable.
Ecuries   = la matiere documentaire doit etre assainie.
```

La Biche travaille l'intention avant la requete.

Le Sanglier travaille le reel brut avant la production.

Les Ecuries travailleront la qualite de la matiere documentaire avant son exploitation.

## 1. Le recit mythologique

Le Sanglier d'Erymanthe est une bete sauvage qui ravage la region.

Hercule doit le capturer vivant et le rapporter a Eurysthee.

Il ne s'agit pas seulement de tuer une menace.

Il faut la maitriser, la contenir, la deplacer.

Selon les versions, Hercule pousse le sanglier dans la neige profonde pour ralentir sa course et le rendre capturable.

Ce detail est important.

Hercule ne repond pas au chaos par un choc frontal.

Il change le terrain.

Il amene la force brutale dans un milieu ou elle devient saisissable.

Le geste central n'est donc pas la destruction.

C'est le cadrage : transformer une force confuse, rapide et dangereuse en objet que l'on peut approcher, tenir et rapporter.

## 2. Themes profonds

Le Sanglier parle du reel brut.

Le reel professionnel ne se presente pas sous forme de prompt propre.

Il se presente comme accumulation :

```text
demandes clients ;
versions de documents ;
plans anciens ;
notes orales ;
messages rapides ;
photos ;
contraintes reglementaires ;
risques ;
urgences ;
contradictions ;
silences ;
implicites ;
pressions ;
pieces manquantes.
```

L'IA sait tres bien produire une coherence a partir de cette matiere.

Mais cette coherence peut etre une fiction de synthese.

Si le reel n'est pas cadre, l'IA peut choisir elle-meme le probleme, la hierarchie, les priorites et le niveau de decision.

```text
Un chaos non cadre
demande a l'IA
de choisir le monde a notre place.
```

## 3. Transposition IA

Le Sanglier apparait lorsque l'utilisateur arrive avec un dossier sale, pressant ou multiple.

Il veut que l'IA aide rapidement.

Mais avant de produire, il faut faire entrer le dossier dans un cadre minimal :

```text
contexte ;
probleme ;
objectif ;
contraintes ;
faits ;
hypotheses ;
inconnues ;
risques ;
exclusions ;
decisions attendues ;
statut de sortie ;
perimetre de responsabilite.
```

Sans cela, l'IA peut confondre :

```text
fait et interpretation ;
urgence et importance ;
information utile et bruit ;
hypothese et decision ;
contexte et instruction ;
contrainte metier et preference ;
brouillon et livrable.
```

Le Sanglier impose donc un geste de situation.

```text
Avant de produire,
il faut situer.
```

## 4. Changer le terrain

Dans le mythe, Hercule pousse le sanglier vers un terrain qui le rend capturable.

Avec l'IA, changer le terrain signifie transformer le chaos en structure de travail.

Le bon cadre ne supprime pas le desordre.

Il le rend lisible.

Il cree des cases provisoires :

```text
ce que l'on sait ;
ce que l'on croit savoir ;
ce qui manque ;
ce qui contredit ;
ce qui presse ;
ce qui engage ;
ce qui doit etre verifie ;
ce qui ne doit pas encore etre decide.
```

Cette operation est decisive dans les metiers documentaires et de conception.

Le cadre n'est pas un appauvrissement.

C'est une condition d'action juste.

```text
Le cadre ne reduit pas le reel ;
il lui donne une forme de travail.
```

## 5. Capturer vivant

Comme pour la Biche, le Sanglier doit etre capture vivant.

Mais le sens est different.

La Biche est fragile : elle ne doit pas etre abimee.

Le Sanglier est brutal : il ne doit pas etre laisse sauvage.

Capturer vivant signifie ici : ne pas tuer la complexite.

Il ne faut pas simplifier au point de perdre le reel.

Il ne faut pas non plus laisser la complexite rendre l'action impossible.

Le cadre doit rester capable de porter la contradiction.

```text
Cadrer le chaos,
ce n'est pas faire semblant qu'il est simple.
C'est le rendre travaillable sans le falsifier.
```

## 6. Le piege

Le piege du Sanglier est la coherence prematuree.

L'IA peut produire une synthese propre trop tot.

Elle peut raconter un dossier comme s'il avait deja un ordre.

Elle peut lisser les tensions.

Elle peut privilegier ce qui est le plus facile a formuler.

Elle peut transformer une masse contradictoire en histoire plausible.

```text
La coherence d'une synthese
peut masquer
le desordre qu'elle n'a pas resolu.
```

Le Sanglier demande donc de faire apparaitre les tensions au lieu de les cacher.

## 7. Difference avec Biche et Ecuries

La Biche concerne l'intention avant la requete.

Le Sanglier concerne la situation brute.

Les Ecuries concernent la proprete de la matiere documentaire.

```text
Biche   : que veut-on saisir ?
Sanglier : dans quel cadre le reel devient-il praticable ?
Ecuries : la matiere fournie est-elle saine ?
```

## 8. Discipline active

Avant toute production, demander un cadrage :

```text
resume du contexte ;
faits etablis ;
hypotheses ;
contradictions ;
points manquants ;
risques ;
acteurs ;
contraintes ;
exclusions ;
niveau d'urgence ;
niveau d'engagement ;
sortie attendue.
```

Puis imposer une sortie de cadrage avant tout livrable :

```text
Ne produis pas encore.
Cadre le dossier.
Separe faits, hypotheses, risques, inconnues et decisions.
Indique ce qui est trop incertain pour conclure.
Propose seulement ensuite une sortie candidate.
```

Dans une logique Pantheon :

```text
reel brut != contexte gouverne
synthese claire != cadrage juste
urgence != priorite
information disponible != fait etabli
contradiction != bruit a supprimer
cadre != reduction du reel
```

## 9. Exemple concret

### Prompt faible

```text
Voici tous les elements du dossier. Fais-moi une synthese claire.
```

Risque : la synthese produit un ordre artificiel.

### Prompt Sanglier

```text
Avant toute synthese, cadre le dossier.
Classe les elements en :
1. faits etablis ;
2. hypotheses ;
3. contradictions ;
4. pieces manquantes ;
5. risques ;
6. decisions a prendre ;
7. elements hors perimetre.

Ne conclus pas encore.
Indique ce qui rend le dossier praticable et ce qui reste chaotique.
```

### Sortie attendue

```text
Produit une carte de cadrage :
- contexte ;
- probleme ;
- enjeux ;
- contraintes ;
- inconnues ;
- prochaine action sure.
```
