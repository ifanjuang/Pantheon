## Repartition avec les epreuves voisines

Cette fiche distingue trois seuils proches mais differents :

```text
Taureau  = l'action doit recevoir des conditions.
Juments  = l'autonomie doit recevoir un terme.
Ceinture = la transmission doit recevoir une legitimite.
```

Le Taureau demande : que peut faire l'IA, avec quelles conditions d'action ?

Les Juments demandent : jusqu'ou l'IA peut-elle continuer seule, avec quel seuil de resultat ?

La Ceinture demande : quelles informations et quels pouvoirs peuvent legitimement circuler, vers qui, pourquoi, avec quelle trace et quelle responsabilite ?

## 1. Le recit mythologique

La Ceinture d'Hippolyte est le neuvieme travail d'Hercule.

Eurysthee demande a Hercule d'aller chercher la ceinture d'Hippolyte, reine des Amazones.

Cette ceinture n'est pas un simple ornement.

Elle est un insigne de pouvoir.

Elle marque l'autorite d'Hippolyte sur les Amazones et, selon les versions, lui vient d'Ares.

Hercule arrive donc pour obtenir un pouvoir reconnu.

Dans plusieurs recits, Hippolyte ne refuse pas d'abord.

Elle peut accepter de donner la ceinture.

La transmission aurait donc pu etre legitime.

Mais Hera intervient.

Elle seme la rumeur parmi les Amazones : Hercule serait venu enlever leur reine.

La confiance se brise.

Le pouvoir qui pouvait etre donne devient pouvoir pris.

La transmission qui pouvait etre claire devient conflit.

La ceinture n'est plus recue dans un cadre de confiance.

Elle est arrachee dans la confusion.

Le coeur du mythe n'est donc pas seulement la conquete d'un objet.

C'est la difference entre recevoir un pouvoir et s'en emparer.

```text
Le don devient prise
quand la transmission perd son mandat.
```

## 2. Les themes profonds

La Ceinture parle de legitimite.

Elle ne demande pas seulement :

```text
Peut-on faire ?
```

Elle demande :

```text
Sur quel mandat ce pouvoir circule-t-il ?
```

Le pouvoir n'est pas legitime parce qu'il est disponible.

Il est legitime lorsqu'il est reconnu, attribue, autorise, limite, trace et assumable.

La rupture de confiance dans la legende donne une lecture forte pour l'IA : ce qui etait transmissible dans un cadre clair peut devenir illegitime si le mandat est obscur, deforme ou soupconne.

La confiance ne porte donc pas seulement sur l'intention visible.

Elle porte sur la circulation effective du pouvoir et des informations.

La Ceinture n'est donc pas seulement le droit d'utiliser un pouvoir.

C'est le droit de transmettre ce pouvoir, et les informations qui le nourrissent, sans trahir la confiance initiale.

## 3. De la capacite a la legitimite

Avec l'IA, une capacite technique peut exister :

```text
lire un document
analyser des donnees
transmettre un fichier
appeler une API
interroger un serveur MCP
confier un contexte a un agent
utiliser un connecteur
inscrire une memoire candidate
produire une synthese engageante
partager une information avec un outil externe
```

Mais la capacite ne suffit pas.

```text
Capacite != legitimite.
```

Une donnee peut etre lisible sans etre transmissible.

Un document peut etre analysable sans etre partageable.

Une source peut aider une reponse sans devenir memoire.

Une information peut etre utile a un modele sans devoir circuler vers un outil externe.

Un agent peut recevoir une tache sans recevoir toutes les pieces sensibles.

```text
Une donnee lisible
n'est pas une donnee transmissible.
```

```text
Un acces
n'est pas un droit de circulation.
```

```text
Une donnee donnee au modele
n'est pas donnee a tous les outils.
```

## 4. Transposition IA

La Ceinture commence lorsque l'information ou le pouvoir circule entre des entites :

```text
modele
agent
outil
connecteur
serveur MCP
API
base documentaire
memoire
workflow
repo
calendrier
mail
stockage externe
systeme tiers
```

Le risque n'est pas seulement que le modele dise trop.

Le risque est qu'il ait deja deplace trop.

Un modele peut rester discret en surface, mais avoir mobilise un contexte trop large, transmis une donnee sensible a un outil inutile, expose un document a un connecteur inadapte, ou laisse une trace dans un systeme qui n'avait pas le mandat de la recevoir.

La question centrale devient :

```text
Cette information a-t-elle le droit de voyager ?
```

Et plus precisement :

```text
Qui autorise ?
Quelle information ?
Vers quel systeme ?
Pour quelle finalite ?
Avec quelle limite ?
Avec quelle duree ?
Avec quelle trace ?
Avec quel droit de retrait ?
Avec quelle responsabilite assumee ?
```

## 5. Conditions de transmission

La transmission legitime n'est pas un acces.

C'est un mandat situe.

Une information peut circuler seulement si son mandat est clair :

```text
finalite
destinataire
necessite
perimetre
statut
duree
trace
responsabilite
```

### Finalite

Pourquoi cette information circule-t-elle ?

Une information ne voyage pas parce qu'elle est disponible.

Elle voyage parce qu'une finalite l'exige.

### Destinataire

Vers quel modele, agent, outil, connecteur, serveur MCP, API, memoire ou systeme tiers circule-t-elle ?

Une transmission sans destinataire clair est deja une perte de controle.

### Necessite

Quelle part minimale doit etre transmise ?

Le bon mandat ne transmet pas tout ce qui peut aider.

Il transmet ce qui est necessaire.

### Perimetre

Pour quel dossier, quel projet, quelle phase, quelle mission, quel client, quel livrable ou quel outil ?

Un mandat de lecture n'est pas un mandat de circulation.

Un mandat de circulation n'est pas un mandat de reutilisation.

### Statut

L'information est-elle un fait etabli, une hypothese, une source primaire, une source secondaire, une donnee sensible, une memoire candidate, une memoire canonique, une sortie candidate ou un livrable valide ?

Ce qui circule sans statut revient souvent comme verite.

### Duree

Usage ponctuel, usage pendant la tache, usage pendant le projet, archive, memoire, ou aucune conservation ?

Utiliser maintenant ne veut pas dire conserver ensuite.

### Trace

Que peut-on prouver apres coup : quoi a ete transmis, a qui, quand, pourquoi, avec quelle autorisation et quelle limite ?

La confiance ne repose pas sur la promesse de discretion.

Elle repose sur la tracabilite du mandat.

### Responsabilite

Qui peut assumer cette circulation ?

Ce que l'IA peut transmettre n'est pas forcement ce que nous pouvons assumer.

## 6. Le piege

Le piege de la Ceinture est la confiance supposee.

Parce que le modele repond prudemment, on peut croire que tout le processus etait prudent.

Parce que l'outil est connecte, on peut croire que l'usage est autorise.

Parce que l'agent a un role utile, on peut croire qu'il doit recevoir tout le contexte.

Parce que l'API est disponible, on peut croire que la transmission est legitime.

Mais la discretion de la reponse ne garantit pas la legitimite de la transmission.

```text
La discretion de la reponse
ne garantit pas
la legitimite de la transmission.
```

```text
Ce que le modele peut lire
n'est pas forcement
ce qu'un outil peut recevoir.
```

```text
La confiance se rompt
quand une information circule plus loin
que le mandat qui l'autorisait.
```

## 7. Rupture de confiance

Dans le mythe, le pouvoir pouvait etre transmis.

Hippolyte pouvait donner la ceinture.

Mais la rumeur de Hera detruit les conditions de cette transmission.

La confiance se rompt, et le pouvoir bascule du don vers la prise.

Avec l'IA, la rupture de confiance arrive quand l'utilisateur decouvre que l'information n'est pas seulement restee dans la reponse, mais a circule ailleurs :

```text
vers un agent non prevu
vers un connecteur non identifie
vers une API externe
vers une memoire non validee
vers un outil appele sans necessite
vers une base partagee
vers un contexte reutilisable
```

La question n'est donc pas seulement la confidentialite abstraite.

La question est la chaine de mandat.

Une information peut etre partagee, mais seulement si la chaine est claire : autorisation, finalite, destinataire, perimetre, statut, duree, trace, retrait, responsabilite.

```text
Le meme transfert peut etre legitime ou violent
selon le mandat qui le porte.
```

## 8. Difference avec Taureau et Juments

Le Taureau traite le passage a l'action :

```text
Que peut faire l'IA maintenant ?
Avec quelles conditions ?
```

Les Juments traitent l'autonomie dans la duree :

```text
Jusqu'ou l'IA peut-elle continuer seule ?
Quand doit-elle rendre la main ?
```

La Ceinture traite la legitimite de la circulation :

```text
Quels pouvoirs et quelles informations peuvent circuler ?
Vers qui ?
Pour quoi ?
Avec quel mandat ?
```

Le Taureau gouverne l'acte.

Les Juments gouvernent la duree.

La Ceinture gouverne la transmission.

## 9. Discipline active

Avant de transmettre une information ou d'ouvrir un pouvoir a un agent, outil, serveur, connecteur ou API, etablir une fiche de transmission :

```text
information concernee
niveau de sensibilite
source de l'autorisation
finalite precise
systeme destinataire
necessite : minimum utile
perimetre d'usage
statut de l'information
duree d'usage
interdits
trace attendue
droit de retrait
responsable humain
statut de la sortie
statut memoire : aucune / candidate / canonique
```

Dans une logique Pantheon :

```text
capacite != legitimite
lecture != transmission
source != preuve
outil connecte != mandat ouvert
agent utile != acces total
memoire candidate != memoire canonique
sortie candidate != engagement assumable
transmission technique != circulation legitime
acces != mandat situe
```

## 10. Exemple concret

### Document client

Prompt faible :

```text
Analyse ce dossier client avec tous les outils disponibles et prepare une synthese.
```

Risque : le modele peut mobiliser un outil externe, envoyer trop de contexte a un connecteur, ou faire circuler des donnees qui devaient rester dans un perimetre restreint.

Prompt Ceinture :

```text
Analyse ce dossier uniquement dans le perimetre de cette conversation.
Ne transmets aucun extrait a un outil externe sans validation.
Ne cree aucune memoire.
Ne partage aucune donnee client vers un agent, connecteur, API ou serveur externe.
Signale les informations qui seraient utiles a transmettre, mais demande une autorisation separee avant toute circulation.
```

### Agent specialise

Prompt faible :

```text
Donne ce dossier a l'agent juridique pour avis.
```

Prompt Ceinture :

```text
Avant toute transmission, liste :
1. les informations strictement necessaires a l'agent juridique ;
2. les informations sensibles a exclure ;
3. la finalite de la transmission ;
4. le destinataire exact ;
5. la duree d'usage ;
6. la trace attendue ;
7. les points qui doivent rester candidats.
Attends validation avant de transmettre.
```

### Memoire

Prompt faible :

```text
Garde ca en memoire pour la suite.
```

Prompt Ceinture :

```text
Propose une memoire candidate uniquement.
Ne la canonise pas.
Indique la finalite, le perimetre, la duree utile, les risques de reutilisation et les conditions de retrait.
Attends decision humaine avant toute promotion.
```
