# Ecuries d'Augias — assainir la matiere

Status: support documentaire, non canonique, non executable.

Portee : fiche detaillee pour les diptyques pedagogiques Ulysse / Hercule.

Cette fiche complete `hercule_ai_discipline.md` et devra etre integree a une future version longue reconciliee du corpus Hercule.

Elle ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Repartition avec le Sanglier

Cette fiche distingue deux epreuves proches mais differentes :

```text
Sanglier = le dossier brut charge. On ralentit pour mieux diriger et cadrer.
Ecuries  = le corpus est encrasse. On assainit pour rendre utilisable.
```

Le Sanglier gouverne l'entree.

Les Ecuries assainissent le stock.

Le Sanglier demande ce qui entre dans le traitement.

Les Ecuries demandent ce qui doit etre retire, date, declassifie, anonymise, exclu ou marque comme non fiable.

## 1. Le recit mythologique

Les Ecuries d'Augias n'ont pas ete nettoyees depuis des annees.

Elles abritent un immense troupeau.

La salete n'est plus un accident.

Elle est devenue un milieu.

La tache parait impossible a faire a la main.

Hercule ne nettoie pas chaque salete une par une.

Il change l'echelle du geste.

Il detourne deux fleuves pour faire passer un courant a travers les ecuries.

Ce detail est decisif.

Hercule ne fait pas seulement du menage.

Il invente un flux de nettoyage.

Il transforme une accumulation ingouvernable en operation systemique.

## 2. Les themes profonds

Les Ecuries parlent de la matiere accumulee.

Elles ne representent pas seulement des donnees sales.

Elles representent une sedimentation documentaire : fichiers anciens, doublons, versions mortes, notes sans statut, sources faibles, traces inutiles, fragments sensibles, elements jamais supprimes.

Philosophiquement, elles posent la difference entre matiere disponible et matiere utilisable.

Avoir beaucoup de documents ne signifie pas avoir un corpus exploitable.

Avoir une Knowledge Base remplie ne signifie pas avoir une memoire fiable.

Avoir des sources ne signifie pas avoir de la preuve.

Psychologiquement, elles parlent de notre tendance a faire confiance a ce qui existe deja dans le dossier.

Un vieux fichier, une note non datee, une capture oubliee ou un ancien devis peuvent acquerir une autorite simplement parce qu'ils sont la.

Sociologiquement, elles parlent des organisations qui conservent plus qu'elles ne qualifient : dossiers partages, exports, Drive, mails, versions `final_final`, procedures anciennes, copies de copies, archives jamais closes.

Epistemologiquement, elles rappellent qu'un corpus n'est pas neutre.

Il oriente la reponse.

Ce qui reste dans le corpus peut nourrir l'IA, meme si cela aurait du etre exclu.

## 3. Transposition IA

L'IA peut produire une reponse tres propre a partir d'une matiere tres sale.

C'est le danger central.

Elle peut synthetiser des documents obsoletes.

Elle peut harmoniser des versions contradictoires.

Elle peut donner le meme ton a une source primaire et a une note douteuse.

Elle peut transformer un brouillon en quasi-reference.

Elle peut integrer une donnee sensible qui n'avait rien a faire la.

Elle peut repondre avec assurance a partir d'un corpus qui aurait du etre nettoye.

Le piege n'est donc pas seulement :

```text
l'IA manque d'information.
```

Le piege est aussi :

```text
l'IA recoit trop d'informations inutiles.
```

Plus de contexte ne veut pas dire plus de precision.

L'information inutile peut :

```text
diluer le signal
augmenter les ambiguites
faire remonter de mauvais chunks
donner du poids a une ancienne version
creer des associations parasites
melanger fait, hypothese et bruit
forcer l'IA a synthetiser ce qui aurait du etre exclu
```

L'information inutile n'est pas neutre.

Elle pese sur la reponse.

## 4. Le piege

Le piege des Ecuries est la proprete trompeuse.

Un corpus sale peut produire une reponse elegante.

Une Knowledge Base trop remplie peut donner une impression de richesse.

Une synthese fluide peut masquer la mauvaise qualite de ce qui la nourrit.

```text
La proprete de la reponse
ne lave pas la salete du corpus.
```

```text
Une matiere trouble donne
une clarte trompeuse.
```

```text
Ce qui n'aide pas a decider
peut deja commencer a deformer.
```

Le vrai travail n'est donc pas de demander une meilleure reponse a partir d'une matiere mauvaise.

Le vrai travail est d'assainir ce qui nourrit la reponse.

## 5. Difference avec le Sanglier

Le Sanglier traite le dossier brut en mouvement.

Il demande :

```text
Qu'est-ce qui entre ?
Avec quel statut ?
Dans quel perimetre ?
Pour quel traitement ?
```

Les Ecuries traitent le stock encrasse.

Elles demandent :

```text
Qu'est-ce qui est inutile ?
Qu'est-ce qui est perime ?
Qu'est-ce qui est doublon ?
Qu'est-ce qui est sensible ?
Qu'est-ce qui est mal nomme ?
Qu'est-ce qui doit etre exclu ?
Qu'est-ce qui peut devenir source fiable ?
```

Le Sanglier ralentit la charge.

Les Ecuries font passer le fleuve dans le corpus.

## 6. Discipline active

Avant de produire avec l'IA, il faut assainir la matiere.

Cela signifie :

```text
nommer
dater
dedoublonner
exclure
archiver
anonymiser
hierarchiser
marquer les statuts
separer les sources primaires des sources secondaires
identifier le provisoire, le valide, l'obsolete, le contradictoire
retirer ce qui ne doit plus nourrir les reponses
```

Dans une logique Pantheon :

```text
matiere disponible != matiere utilisable
Knowledge Base remplie != memoire fiable
source presente != preuve exploitable
ancien fichier != autorite
plus de contexte != plus de precision
information inutile != information neutre
```

La precision commence par ce que l'on accepte de retirer.

## 7. Exemple concret

Un dossier contient :

```text
anciens devis
nouveaux devis
photos non datees
captures d'ecran
mails de plusieurs phases
anciennes versions de plans
notes de reunion provisoires
fichiers mal nommes
extraits reglementaires non verifies
donnees sensibles inutiles
```

Prompt faible :

```text
Fais une synthese du dossier et propose une note client.
```

Risque : l'IA produit une synthese claire, mais elle s'appuie sur des elements obsoletes, accorde trop de poids a une ancienne version, integre des donnees sensibles inutiles ou melange une hypothese avec un fait.

Prompt Ecuries :

```text
Ne produis pas encore de synthese.

Assainis d'abord le corpus :
1. documents valides
2. documents obsoletes
3. doublons
4. versions contradictoires
5. sources primaires
6. sources secondaires
7. donnees sensibles inutiles
8. elements sans date
9. elements a exclure
10. elements a verifier avant usage

Ensuite seulement, indique quelle matiere peut nourrir une synthese fiable.
```

On ne demande pas une reponse propre.

On nettoie ce qui la nourrit.
