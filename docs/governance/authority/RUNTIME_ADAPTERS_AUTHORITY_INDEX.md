# Pantheon Next — Runtime Adapters Authority Index

Status: candidate support map — populated (runtime-adapters migration group); awaiting review.

This sub-index carries runtime-adapter rows migrated out of `docs/governance/AUTHORITY_INDEX.md`. It keeps tool-specific material away from the tool-agnostic kernel table while preserving the placement rule.

It does not override the authority vocabulary, promotion rule, placement test, tool naming rule, terminology boundary rule or sensitive-path guardrail of `docs/governance/AUTHORITY_INDEX.md`. The master index defines how to read authority; this file only lists where documents sit. Moving a row here changes no authority class and promotes nothing.

Repository-name references to former `pantheon-mvp` PRs or commits are provenance only after the monorepo import. Current Pantheon implementation placement is under `implementation/`. `external implementation` remains valid only for genuinely external runtimes/adapters such as Hermes or product-native services; it must not be read as a second active Pantheon implementation repository.
