# Anti-pattern: Canvas as Evidence Pack

Status: reference — implemented as documentation.

A visible canvas can improve supervision.

It is not an Evidence Pack by itself.

## Symptom

A visible conversation, board, timeline or agent canvas is treated as sufficient proof because the activity was observable.

## Pantheon rule

```text
Visibility is not validation.
A canvas is not an Evidence Pack.
```

## Correction

Require:

- selected sources;
- Evidence Items;
- assumptions;
- limitations;
- contradictions;
- approval state;
- memory boundary.

## Final rule

```text
A canvas shows activity.
An Evidence Pack structures proof.
```
