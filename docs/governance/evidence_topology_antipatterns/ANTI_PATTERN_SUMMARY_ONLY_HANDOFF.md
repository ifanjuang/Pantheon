# Anti-pattern: Summary-only Handoff

Status: reference — implemented as documentation.

A handoff that contains only a prose summary is not enough for consequential work.

Required correction:

- add a clear claim;
- add a source locator;
- state the scope of support;
- state limitations;
- state open questions;
- state approval gaps when relevant.

Final rule:

```text
Summaries help navigation.
Evidence supports decision.
```
