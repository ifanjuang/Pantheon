# Professional Examples

Status: fictional examples — educational support only.

These examples show how Pantheon Next can frame AI-assisted work on professional dossiers.

They are not governance doctrine, implementation, professional advice or proof that Pantheon prevents professional fault.

They illustrate a method:

```text
request
→ situation intake
→ mission sheet / Task Contract
→ governed sources and scope
→ Evidence Pack Candidate
→ candidate deliverable
→ human decision/review
→ Register Candidate only if separately authorized and admitted
```

Current boundary:

```text
Hermes clients handle runtime interaction.
Hermes Agent executes externally.
Pantheon Cockpit exposes governed projections.
Pantheon Next governs consequential status and Evidence rules.
The human decides where required.
```

## Reading rule

Each example should make visible:

- what the professional asked;
- how the situation was clarified before execution preparation;
- which sources were allowed or excluded;
- what was assumed;
- what contradicted what;
- what stayed candidate;
- what required human validation;
- what could or could not become governed Register material.

## Boundary

The examples may use Pantheon vocabulary such as `Dossier Situation Intake`, `Task Contract`, `Evidence Pack`, `Register Candidate`, `Registre Probatoire`, `Governance College`, `Evidence Topology Gate`, `Module Activation`, `Role Activation`, `Effective Policy` or `User Decision Gate`.

They do not create runtime behavior, define new authority schemas or authorize Hermes, a client, a provider or any external model to perform real professional acts without the applicable governed decision path.

```text
retrieved != truth
memory != Evidence
runtime success != authorization
projection != persistence
provider selected != authority transfer
```
