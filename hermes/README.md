# Hermes Integration

This directory contains Pantheon-governed Hermes profile templates and related execution-context specifications.

Pantheon Next does not install Hermes profiles automatically.
Pantheon Next does not activate Hermes.
Pantheon Next does not provide an execution runtime.

Hermes executes.
Pantheon governs.

## Phase 1 scope

Phase 1 keeps Hermes profiles lightweight:

```text
hermes/profiles/<profile>/
  README.md
  profile.yaml
  soul.md
```

No per-profile `governance.md` is used in phase 1.

The canonical role source remains:

```text
docs/governance/AGENTS.md
```
